ポートフォリオサイト

コンセントのポートフォリオ

HTML・CSSを用いて制作した、自身のポートフォリオサイトです。

「見やすさ」と「自分らしさ」の両立をテーマにデザインしました。

背景には完全な黒ではなく、落ち着いたダークグレーを採用し、 長時間閲覧しても目が疲れにくい配色を意識しています。

アクセントカラーには黄色を使用し、 重要な情報が自然と目に入るよう工夫しました。

また、作品ごとに異なるアクセントカラーを設定することで、 それぞれの作品の個性を引き立てるデザインを目指しています。

使用技術

  • HTML
  • CSS
  • JavaScript（詳細表示機能など）

Eclipse Lab

ECLIPSE LAB ARCHIVE

架空の研究施設「Eclipse Lab」を舞台とした、 アーカイブ探索型のゲーム作品です。

プレイヤーは施設から残されたArchiveへアクセスし、 様々な記録を読み進めながら、かつてこの場所で何が起きたのか、 そしてEclipse Labに隠された真相を辿っていきます。

使用技術

  • HTML
  • CSS
  • JavaScript

Archiveの探索や権限による情報の解禁、記録の閲覧など、 JavaScriptを多用してゲームとしてのインタラクションを実装しています。

研究施設や異常な存在を扱う、少しダークな世界観の作品です。 詳細な設定や物語は、Archiveを探索することで徐々に明らかになっていきます。
