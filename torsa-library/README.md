# トルサ図書館（試作）

## フォルダ構成

```
torsa-library/
├─ index.html        … 画面・館内・本・部屋（ふだんは触らなくてOK）
├─ tools/theme/     … 棟ごとの色ちがいの部品を作るプログラムと、色の決まり（themes.json）
├─ event-preview.html … イベントだけを確認するページ
├─ donate.html       … 寄贈の間（だれでも本を作って寄贈できるページ）
├─ book_data/        … 寄贈された本のファイルを入れるフォルダ（入れるだけで書架に並ぶ）
├─ js/
│  ├─ torsa.js       … トルサの動きと、さわったときの反応（いじるならここ）
│  ├─ cover-parts.js … 部品を組み合わせて作る表紙と、「表紙をつくる」画面
│  ├─ cover-core.js  … 表紙を描く共通の道具（寄贈の間で使う）
│  ├─ book-gifts.js  … book_data の寄贈本を読みこんで、空いた棚に並べる
│  └─ sheep.js       … 羊の間（トルサの部屋）と、本館の東のはしからつづく廊下
├─ kaneru/           … カネル（好感度100のイベントと、赤い月の間）。くわしくは kaneru/README.md
├─ event/            … イベントと、胸・腰の特別な反応のプログラム（くわしくは event/README.md）
│  ├─ events.js      … イベントの進行と、イベント中のさわったときの反応（全画面の一枚絵が部品ごとに動く）
│  ├─ events.json    … イベントの設定（セリフ・表情・いつ起こるか・さわったときの反応）
│  ├─ events/        … イベントの絵（1イベント＝1ファイル。部品ごとのレイヤー）と説明（README.md）
│  ├─ touch-specialness.js … 胸・腰の特別なさわられ方の動き
│  ├─ touch-specialness.json … 胸・腰のセリフ・使う表情・連続でさわるときの間隔
│  └─ README.md      … このフォルダの説明
├─ assets/
│  ├─ torsa/         … トルサの表情（normal 通常 / blush 照れ / sweat 汗）
│  ├─ covers/        … 表紙画像を置く場所（テンプレートを使わないとき）
│  ├─ parts/         … 館内の部品（サイトが使う版）
│  ├─ parts-src/     … 受け取った部品の元ファイル（手を加えていない）
│  ├─ themes/        … 棟ごとの色ちがいの部品（east／west／annex／vault。tools/theme/make_themes.py で作る）
│  └─ svg/           … 星空・感情記号・吹き出しの SVG 素材
└─ data/
   ├─ library.json   … 館内の広さ・本棚の位置・場所の名前・棟（本館／東の書館／西の書館）
   ├─ scene.json     … 部品の一覧・大きさ・合わせ位置と、飾り（ツタ・水晶玉・漂う本）の設定
   ├─ books.json     … 本のキャラクター（性格・セリフ・感情・表紙・置き場所）
   ├─ works.json     … 収録作品の本文
   ├─ torsa.json     … トルサのセリフ
   ├─ rooms.json     … 禁書庫の設定・年齢確認の文章・部屋のささやき（図書館の間の寄贈の扉・羊の間も）
   ├─ event-notice.json … イベントが始まる前の「見る／今は見ない」の画面の文（注意書き）
   ├─ bgm.json       … BGMの設定
   └─ sfx.json       … 効果音の設定（音量・個別のオンオフ・音声ファイルへの差し替え）
```

本のセリフ（books.json）と作品本文（works.json）は別ファイルなので、片方を直してももう片方は壊れません。
本と作品は books.json の `workId` で結びついています。

## よくある変更

- **作品の本文を差し替える** … works.json の `paragraphs` に段落ごとに文章を入れる。空行は `""`。
- **本を1冊増やす** … くわしくは「本の追加ガイド.md」。works.json に作品を1つ、books.json に本を1冊追加して `workId` を合わせる。
  `type` は `revisit`（再訪で変わる）／`friendly`（親しげ）／`jumper`（飛び出す）／`refuser`（読ませてくれない）のどれか。
- **表紙を部品から作る** … URLの最後に `?covers` を付けて開くと「表紙をつくる」画面が出ます。部品は「地・ふち・紋章・題名・小物と仕上げ」の見出しで切りかえて選びます。種類の数は「なし」を除いて、地（素材21種）・背景の絵（32種：戦場・和風・洋館・LOVE・ファンタジー・ドラゴン・龍・蛇・蜘蛛の巣・虹・中華風など）・地模様（23種）・ちらし（16種）・背（9種）・枠（35種）・角の飾り（15種）・帯（11種）・紋章（38種）・紋章の台（15種）・題名の札（15種）・題名の飾り（7種）・留め具（10種）・しおり（4種）・仕上げ（8種）、それに題名と紋章の位置。部品ごとの「おまかせ」と「ぜんぶおまかせ」もあります。できたら「書き方をコピー」を押して、books.json の本の `"cover"` に貼りつけます（`cover.parts` を書いた本は部品の表紙、書かない本は今までどおり template の表紙）。部品のプログラムは js/cover-parts.js（PARTS に名前の一覧）。
- **表紙を変える** … books.json の `cover` で、形（`template`）・地の色（`color`）・飾りの色（`accent`）・題名（`title`）・副題（`subtitle`）・紋章（`emblem`）・縦書き／横書き（`titleDirection`）を選べます。選べる名前は books.json の先頭に書いてあります。形は15種類、紋章は14種類。URLの最後に `?covers` を付けて開くと、全部の見本を一覧で見られます。
  描いた表紙画像を使いたいときは `cover.image` にパスを書く（例: `"assets/covers/tsun.png"`）。
- **本の感情** … セリフごとの `emote` を変えると、吹き出しの形と、まわりの記号（汗・照れ線・怒りマーク・音符・Zzz など）が変わります。使える名前は books.json の先頭に書いてあります。
- **本の置き場所** … books.json の `place`（bay＝本棚ID、row＝段、slot＝左から何冊目あたり）。
- **館内の部品を差し替える** … assets/parts/ の同じ名前のファイルを上書きする。大きさが変わったら scene.json の `vb`（と `fit`）を直す（わからなければ、ファイルを渡してくれれば直します）。
- **館内を広げる（本棚を増やす）** … library.json の `bays` に本棚を1つ足す。`x` は 460 ずつずらす（東の端なら `{ "id": "e4", "x": 3550, "seed": 79 }`、西の端なら `{ "id": "w0", "x": -350, "seed": 7 }`）。
  柱・アーチ・ランタン・鉢植え・両端の扉・歩ける範囲は自動でついてきます。1460〜2140 は月の窓なので置かないでください。
  増やした棚に本を置くときは、books.json の `place.bay` にその `id` を書く。場所の名前（`zones`）を分けたいときは library.json の `zones` に足す。
- **歩ける範囲** … library.json の `world.endRoom`（端の本棚の柱から先へ歩ける長さ）と `world.eastExtra`（トルサが右にいるぶん、東だけ多めに歩ける長さ）。
- **両端の扉** … 本館の西の扉は「西の書館」、東の扉は「東の書館」につながっています（くわしくは下の「館の棟と禁書庫」）。行き先は library.json の `halls` の `doors` で変えられ、`null` にすると「開かない扉」になって、さわるとトルサが torsa.json の `door` のセリフを言います。
- **星空を差し替える** … library.json の `art.sky` にパスを書く。
- **トルサのセリフ** … torsa.json の各場面の配列に文章を足すと、その中からランダムに選ばれます。
  `{ "text": "…", "face": "blush" }` の形で書くと、そのセリフのあいだ表情が変わります。
  表情の名前は `blush`（照れ：ほっぺたがうっすら赤い）、`soblush`（赤面：真っ赤）、`sweat`（汗）、`surprise`（おどろき）、`sad`（しょんぼり：耳がたれて、少しうつむく）。
- **トルサの頭なで** … 頭の上でクリック（タップ）するか、押したまま左右にこすると、照れ顔になって `pat` のセリフを言います。なでた回数が増えると `patMany` も出ます。 頭の上で押したままにしていても、ときどきなでなでの反応をします（長くなでていると torsa.json の `patHold` のセリフを一度だけ言います）。
- **表情を増やす** … 画像を assets/torsa/ に置き、torsa.json の `faces` に名前とパスを足します。
- **BGM** … bgm.json の `chords`（和音）や `volume`（音量）で雰囲気を変えられます。
  音声ファイルを使いたいときは assets に置いて `audioFile` にパスを書く（例: `"assets/bgm.mp3"`）。

- **効果音** … sfx.json の `volume` で全体の音量、`sounds` の各音を `false` にするとその音だけ止まる。音声ファイルのパスを書くとそのファイルを鳴らす。`typing` は本が話すときの「ぽぽぽ」声。

## パレット（右上のボタン）

右上の「パレット」から、次の4つを開けます。

- **蔵書目録** … 本を探す（くわしくは下の「蔵書目録」）。
- **設定** … 音・演出（くわしくは下の「設定」）。
- **転送** … 書館を選んで、その場へ移動します（本館・東の書館・図書館の間・西の書館・禁書庫）。いまいる場所には「いまここ」と出ます。禁書庫は、まだ年齢確認をしていなければ年齢確認から。転送するときのトルサのセリフは torsa.json の `warp`。点の色は index.html の `WARP_DOT`、並びは `WARP_ORDER`。
- **思い出** … 一度見たイベントを、何度でも見返せます。

## イベント

禁書庫に入ってしばらくすると、トルサが転んで鉢植えの葉っぱに巻かれてしまうイベントが起こります（一度だけ。来館記録をリセットすると、また起こります）。
全画面に一枚絵が出て、トルサが部品ごとに動きます。会話の途中でトルサにさわると反応します。
絵は `event/events/vault-fall.svg`（部品ごとのレイヤー）、設定は `event/events.json`。くわしくは `event/events/README.md`。

## カネル（好感度100のイベント）

好感度が100になると、本館で「赤い月の来訪者」のイベントが起こります。そのあと、西の書館のいちばん奥（禁書庫の扉のさらに左）から、廊下を通って「赤い月の間」に行けるようになります。
プログラムとセリフは kaneru/ フォルダ（event/ とは別）。くわしくは `kaneru/README.md`。

## 館の棟と禁書庫

### それぞれの部屋の色と素材

| 場所 | 色と素材 |
|---|---|
| 本館（月の窓） | 胡桃色の木・紺のカーペット・金・青い水晶・鉢植えの木・月のステンドグラス・天球儀とろうそく（もとの部品そのまま） |
| 東の書館（天体の窓） | 夜の紫檀と真鍮：赤みのこい紫檀の本棚とアーチ・葡萄酒色のカーペット・すもも色の夜の壁・琥珀の水晶。窓の前は六角の天球儀と小さな木、宙に浮かぶ赤いろうそく（橙の火）。床に鉢植えの木、本棚の上にアロエ |
| 西の書館（星の窓） | 夜の銀と白い花：青みの銀の黒檀（本棚・柱・アーチ・窓のふちを同じ色に）・藍のカーペットに銀の模様・群青の夜の壁・紫の水晶。窓のまわりに浮かぶ白いろうそく（藤色の火）。床に白い花の咲く木、本棚の上にユリとカラー。奥は暗く、禁書庫の扉と赤い煙 |
| 図書館の間 | 翠の読書室：館内と同じ組み方（柱・アーチ・左右の本棚）で、まんなかに草木のステンドグラスの大きな窓（生命の木と白い花・シダ）と読書机。柱の上に翠の水晶、展示台の上に翠の火のろうそく、床に鉢植えの木、机の上にユリ |
| 禁書庫（地下） | 石と鉄：灰紫の石の柱とアーチ・石の床と天井・鉄の本棚・鉄格子の窓と赤い光・宙に浮かぶ青い火のろうそく・天井から垂れるしずく・赤い煙・植物なし |

### 棟のつながり

- **東の書館（本館の東の扉）** … 入ると右へ進みます。いちばん東の扉の先が「図書館の間」です。
- **西の書館（本館の西の扉）** … 入ると左へ進みます。奥に行くほど暗くなり、いちばん奥の扉が禁書庫です。
- **禁書庫（西の書館のいちばん奥）** … 入る前に年齢確認が出ます（文章は rooms.json の `forbidden.ageGate`。「入る」を選ぶと、ブラウザを閉じるまでは聞き直しません）。禁書庫も、ほかの棟と同じように歩けます（← → キー・ドラッグ・ボタン）。本は鉄の本棚に入っています。入ってきた扉（東のはし）から西の書館に戻ります。
- **図書館の間（東の書館のいちばん奥）** … 左右の展示台におすすめの本が表紙を見せて並びます（rooms.json の `annex.display`）。机の「目録の箱」で蔵書目録、「今日の一冊」は日付で毎日変わります。

### 設定のしかた

- **棟の設定** … library.json の `halls`。名前・窓・場所の名前（`zones`）・扉の行き先（`doors`）・暗くする側（`dark`）・光の色（`rayColors`）・赤い煙（`smoke`）・しずく（`drips`）・きらめきを出さない（`sparkles: false`）。
- **棟の色と素材（`theme`）** … `recolored` に書いた部品は `dir` のフォルダの色ちがいを使い、`swap` で部品を差しかえ（禁書庫：本棚→鉄の本棚、カーペット→石の床、窓→鉄格子の窓）、`sky` で空（禁書庫は石の天井）を変えます。`decor` で飾りを変えます：`plants`（床に置く鉢植えの部品と幅。床には木を置きます）、`shelfTop`（本棚の上に置く草や花）、`centerpiece`（窓の前に置く部品の一覧 `{ part, x, w }`。書かなければ天球儀と机）、`floaters`（窓のまわりに浮かぶろうそくの部品。ろうそくの色は棟ごとの色ちがい：本館＝ふつう、東＝赤いろうそくに橙の火、西＝白いろうそくに藤色の火、禁書庫＝青い火、図書館の間＝翠の火。宙に浮かぶランタンの中のろうそくも、同じ色にそろえています）、`crystalPart`（水晶玉の部品）、`crystals`・`ivy`・`candles`・`centerpiece`・`front` を `false` にするとその飾りを置かない、`backColors`（奥の壁の色）、`wall: "stone"`（石の壁）。
- **色ちがいの部品の作り直し** … assets/parts/ の部品を描き直したら、トルサ図書館のフォルダで `python3 tools/theme/make_themes.py` を動かすと、東・西・図書館の間・禁書庫の色ちがいがぜんぶ作り直されます。色の決まりは tools/theme/themes.json（色相・あざやかさ・明るさで指定）。禁書庫の新しい部品は `python3 tools/theme/draw_vault_parts.py .` で描き直せます。
- **新しい部品** … tree_a.svg・tree_b.svg（鉢植えの木）、flower_lily.svg・flower_calla.svg（白い花の鉢）、tama_purple.svg（紫の水晶玉）は、いただいた sozai.svg を分けたもの（元のファイルは assets/parts-src/sozai.svg）。grim_shelf.svg（鉄の本棚）・stone_floor.svg（石の床）・vault_gate.svg（鉄格子の窓）・vault_ceiling.svg（石の天井）は禁書庫用に描いたもので、本館の部品と同じ大きさです（鉄の本棚は段の高さも同じなので、本の置き場所がそのまま合います）。
- **sozai2.svg の部品** … orrery_hex（六角の天球儀）・tree_small_a／tree_small_b（小さな木）・blossom_a／blossom_b（白い花の咲く木）・gem_purple（紫の宝石）・candle_blue（青い火のろうそく）・aloe（アロエ）。元のファイルは assets/parts-src/sozai2.svg。
- **窓のガラス** … 窓の上にガラスの表面（つや・映りこみ・枠の内側のかげ）を重ね、ときどき光がすっと走ります（軽量モード・動きを減らす設定では走りません）。窓から差す光は、遠くからでも少し見えて、近づくほど強くなります。
- **Now Loading** … 棟や図書館の間に移るとき、絵が読み込み終わるまで暗転したまま待ち、少し時間がかかるときは右下に「Now Loading...」が出ます。となりの棟の絵は、あいている時間に先に読んでおきます。最初の「入館する」も、本館の絵が読み込まれてから押せるようになります。
- **棟を移ったとき** … 来た扉が画面の中に見える位置に立ちます（西の扉は画面の左寄り、東の扉はトルサに隠れないよう、まんなか寄り）。
- **window_leaf.svg** … 図書館の間の、草木のステンドグラスの窓（tools なしで直接描いたもの。月の窓と同じ大きさ）。
- **本とはしご** … はしごのうしろに来る本は、自動ではしごの右へずらして置きます。
- **棟に本を置く** … books.json の本に `"hall": "east"`・`"west"`・`"vault"`（禁書庫）を書き、`place` で棚の位置を決めます。図書館の間だけに置くなら `"room": "annex"`。禁書庫の本は、年齢確認をするまで蔵書目録にも出ません。
- **禁書庫の中のトルサ** … 禁書庫の中では、セリフも、さわったときのひとことも torsa.json の `vaultLines` を使い、なでたときの照れ顔も汗の顔になります。
- **トルサのセリフ（棟）** … torsa.json の `doorToEast`・`doorToWest`・`doorToMain`・`enterEast`・`enterWest`・`enterMain`・`celestialWindow`・`starWindow`・`doorForbidden`・`doorForbiddenAgain`・`ageDeclined`・`backFromForbidden`・`doorAnnex`・`enterAnnex`・`backFromAnnex`、禁書庫の中は `vaultLines` の `vaultEnter`・`vaultWindow` など。
- **ささやき** … 禁書庫は library.json の `halls.vault.whispers`、図書館の間は rooms.json の `annex.whispers`。ときどき画面の下に出ます。

## 蔵書目録（パレット・図書館の間の目録の箱）

- 題名・作者・カテゴリーなどのことばで探せます（ひらがなとカタカナ、全角と半角の違いは気にしなくてOK）。
- 「場所」（本館／東の書館／西の書館／禁書庫）。図書館の間だけに置いた本があれば「図書館の間」も出ますと「カテゴリー」で絞り込めます。カテゴリーは works.json の `genre` がそのまま使われ、新しい言葉を書くと自動で増えます。
- 禁書庫の本は、年齢確認で「入る」を選ぶまで目録にも出ません。

## 設定（パレットの「設定」）

音楽・効果音のオン／オフと音量、本の声（ぽぽぽ）、演出の段階をここで切り替えられます。選んだ内容はそのブラウザに保存されます。

- **きらきら** … 光や動きをぜんぶ見せる（パソコンの最初の設定）
- **ひかえめ（軽量版）** … 光と動きを少し減らして軽くする（スマホの最初の設定。パソコンでも動きが遅いと自動でこちらになる）
- **オフ（いちばん軽い版）** … きらめきや動く飾りを止める

### 軽く動かすためのくふう（見た目はそのまま）

- 館内の部品の SVG を、見た目を変えずに軽くしました（合計 約4.8MB → 約3.5MB。tools/optimize/README.md）。
- トルサの表情の画像（assets/torsa/*.png、合計約1.2MB）は、部品で動くトルサが使えないときだけ読むようにしました（いままでは毎回読んでいました）。
- カネルの絵と城の絵は、イベントか赤い月の間に行くときに初めて読みます。

- 立ち止まっているときは、館内のきらめき・暗さの層とトルサを1秒に30回だけ描き直し、同じフレームにそろえています（歩いているとき・さわったとき・マウスでトルサが向きを変えるときは、1秒に60回）。
- 本の光・本の背のきらり・天球儀のまわりを回る星・煙は、毎フレーム描き直さずに済む方法で動かしています。煙は小さく描いてから広げています。
- 禁書庫と図書館の間の光や煙は、重ねたときの色をはじめから使っていて、重い「スクリーン」重ねをしていません。
- 流れ星の層は、流れ星が出ているときだけ表示します。
- 画面の大きさを変えたり「見つめる」を押したりしても、トルサやきらめきの層が一瞬消えないようにしています。
- 「動きを減らす」設定のパソコン・スマホでも、夜の暗さと西の書館の奥の暗さ・煙は（止まった絵として）出ます。
- **スマホでの表示**：index.html にスマホ用の画面幅の設定（viewport）が入っていなかったため、スマホでは幅980pxのパソコン用の画面を縮めて表示していて、館内の絵を何倍もの大きさで描いていました（とても重く、開けなくなる原因）。設定を入れて、スマホの幅で表示するようにしました（絵を描くためのメモリが約6分の1）。
- **重い部品を絵に**：本棚・鉢植えの木・花は、細かい線がとても多い SVG だったので、あらかじめ絵（.webp）にしたものを使います。読みこむ量が 約3.8MB → 約1.9MB、入館できるまでの時間も短くなりました（tools/optimize/README.md）。
- **月の窓の光の筋と夜の暗さ**：毎フレーム大きな面を塗っていたのを、立ち位置が変わったときだけ半分の大きさで描き直し、毎フレームはその絵を重ねるだけにしました。
- **窓ガラスのきらめき**：アーチの形に切り抜くのに、重い多角形の切り抜きを使っていたので、同じ形の角丸の切り抜きに変えました。
- 読みこみ中の星（幕が下りていないとき）は止めます。

## トルサの好感度（中身だけ。画面には出ません）

- **たまり方** … 来館する・本を読む（同じ本は1日1回）・本と話す・トルサと話す・トルサにさわる、で少しずつたまります（0〜100）。ふえる量と、続けてふえるまでの待ち時間は torsa.json の `affinity.gain`・`affinity.cooldownSec`。
- **教えてくれる本** … お話し好きの「若草の本」が、2回目からの会話の最後に「相当好かれてるね～」のように、数字ではなく言葉で教えてくれます。セリフは books.json のその本の `affinityReport`（`min` 以上で、いちばん大きい `min` のもの）。ほかの本にも書けます。
- **好感度が高いと** … `affinity.blushFrom`（100）以上で、照れ顔がときどき赤面になります（`blushChance`）。`affinity.lines` に「好感度が min 以上のときに足されるセリフ」を書けます（キーは lines と同じ：talk・idle・pat・afterRead など）。禁書庫の中では足しません。
- **禁書庫のできごと** … 好感度が `affinity.vaultEvent.min` 以上で禁書庫に入ると、vaultLines の `vaultAffinity`（`vaultEvent.key` の名前）のセリフを一度だけ言います。まだセリフは入っていないので、足すまでは何も起きません。プログラムで何かしたいときは、そのとき出る `torsa:vault-affinity` という合図（イベント）を使えます。
- **確認用** … ブラウザのコンソールで `__affinity()` で今の値、`__affinity(100)` で値を変えられます。設定の「来館記録をリセット」で0にもどります。

## トルサのプログラム（js/torsa.js）

トルサの動き（呼吸・ゆれ・顔の向き・表情）と、さわったときの反応（動き・セリフの選び方・長押し）は、`js/torsa.js` にまとめてあります。index.html を開かなくても、このファイルだけで直せます。

- ファイルの先頭に「いじりやすい場所」の一覧があります。名前（`FACE`・`DEPTH`・`PARTS` など）で検索してください。
- index.html から受け取っているのは、画面の部品を探す `$`、効果音 `SFX`、きらめき `FX`、トルサのセリフ `say`、表情 `setFace`、来館記録 `mem` と `save`、読み込んだデータ `DATA` です。
- さわれる場所のボタンは index.html の `<div class="torsa-fig">` の中、位置は rig.json の `zones` で決まります（`placeZones`）。
- 直したあと画面が真っ白になったり、トルサが動かなくなったりしたら、ブラウザの開発者ツール（F12）の「Console」に、何行目がおかしいか出ます。js/torsa.js が読めないときは、トルサは動かない画像で表示されます。

## トルサの動き（部品で動かす）

トルサは、描いてもらったベクター絵（`assets/torsa/rig/src/` の3枚）を部品に分けて、Live2Dのように骨で動かしています。

- **軽くするしくみ** … 読み込んだときに部品を一度だけ絵にしておき、毎フレームは部品の絵をずらして重ねるだけ（約30枚）。ベクターを毎回描き直さないので軽く、「ひかえめ」では1秒30回まで、会話中や読書中は止まります。データは3枚のSVG（合計約490KB）→ `rig.json`（約150KB）。
- **立体的な動き** … 顔がゆっくり見回したり、マウスの方を少し向いたりします。そのとき部品ごとの奥行き（手前の前髪・目は大きく、奥の後ろ髪・角は逆に動く）と、横を向いた側の縮みで立体に見せています。髪は少し遅れて揺れ戻ります。奥行きの数字は js/torsa.js の `DEPTH` で変えられます。
- **ふだん** … 呼吸（吸う→止める→吐く、ときどき深呼吸）、頭のゆらぎ、耳の上下、アホ毛と横髪とマントの揺れ、ときどき片耳がぴくっ、ときどき目が一瞬平らになる（まばたきのかわり）。
- **さわったとき** … 頭＝少し沈んで耳がたれる／角＝さわった角がぴくっ／耳＝さわった耳がぴくぴくっ／鼻＝顔を少し引いて目をきゅっ／ブローチ＝からだごと小さく跳ねる（びくっ）。ブローチのあとは少しして深呼吸します。
- **表情** … torsa.json の表情名がそのまま使えます。blush＝頬の赤み、soblush＝もっと赤く、sweat＝小さな汗と平らな目。
- 動きの大きさは js/torsa.js の中（`case "ear":` など）の数字で調整できます。胸と腰の動きは event/touch-specialness.js、セリフや間隔は event/touch-specialness.json にあります。
- 絵を描き直したときの作り直し方は `tools/rig/README.md` を見てください。
- rig.json が読めないときは、今までの画像（assets/torsa/*.png）で表示します。
- URLに `?zones` を付けると、さわれる場所が見えます。


## 寄贈の間（donate.html）と book_data フォルダ

だれでも本を作って、図書館に寄贈できるページです。若草の本を手に取ると「本を寄贈するには？」のボタンが出て、寄贈のしかたを教えてくれたあと、寄贈の間に案内します（books.json の若草の本の `lines.donate`）。

寄贈の間では、若草の本の案内で、次の順に本を作ります。プログラムの書き方は画面に出ません。

1. 本の名前（題名・作者・カテゴリー）
2. 本文（貼りつけるだけ。1行が1段落、空いた行もそのまま）
3. 表紙（「表紙をつくる」と同じ部品で）
4. 性格（10種類のお手本。選ぶとセリフのお手本が入る）・棚の上のしるし・置いてほしい書館
5. くせ（ふつうの本／通うほど変わる本／飛び出す本／読ませてくれない本）
6. セリフ（くせに合わせて、書く欄が変わる。ひとことずつ気持ち（顔）も選ぶ）
7. ためしに会う（棚から手に取る・飛び出す・断られる・目録から・読み終わる、をその場でためせる）
8. 綴じる（足りないところを教えてくれて、そろうと「寄贈本_○○.json」ができる。スマホでは共有ボタンでそのまま送れる）

書きかけの本はブラウザに自動で保存されます。「綴じた本を開いて直す」で、できたファイルを開いて直すこともできます。

**管理人さんがすること**：受け取った「寄贈本_○○.json」を `book_data` フォルダに入れるだけです。図書館を開くと、空いている棚に自動で並び、蔵書目録にも出ます。しまうときはファイルを出すだけ。フォルダの中身を見せないサーバーに置くときだけ、`book_data/list.json` にファイル名を書き足してください（くわしくは book_data/README.md）。

- ファイルの中身は、決まった形の値（色・部品の名前・セリフ・本文など）だけを取り出して使います。ほかの書き込みは無視されるので、ファイルに何か書き足されていても図書館は壊れません。
- 飛び出す本は、ひとつの棟に1冊までです。2冊目は、飛び出す本のいない棟に置かれます（どの棟にもいるときは、ふつうの本になります）。
- 棚の場所は、寄贈された日の古い順に決まるので、あとから寄贈が増えても、前の本の場所は変わりにくくなっています。


## 羊の間（トルサの部屋）

本館の東のはし（東の書館への扉より右）は、少しずつ暗くなって、そのまま「羊の間への廊下」になります。いちばん奥の扉から、トルサの部屋「羊の間」に入れます（いつでも入れます）。プログラムは js/sheep.js、部屋の名前やささやきは data/rooms.json の `sheep`。

- 廊下は館とおなじ部品（柱・アーチ・壁板・ランタン・鉢植え・扉）に、額絵（おひつじ座・月とひつじ）、扉の上の星のガーランド、ひつじの玄関マットを足しています。
- 部屋は、館の月の窓・大アーチ・柱・机・本棚に、星もようの壁紙と腰板、天蓋のベッド（ひつじのぬいぐるみ・ナイトキャップ・金色の編みもの）、窓のカーテン、ナイトテーブル（月の目ざまし時計・ホットミルク）、星のガーランド、月もようのじゅうたん、毛糸のかご、スリッパ。色は館とおなじ、くるみの木・紺・金です。
- 羊の顔（ぬいぐるみ・スリッパ・玄関マット・額絵）：茶色の丸い顔に、頭を包むもこもこの毛と、顔の横でくるんと巻く金の角（js/sheep.js の sheepFace）。
- さわれる場所と、そのときのセリフ（torsa.json）：天蓋のベッド sheepBed・ぬいぐるみ sheepPlush・ナイトキャップ sheepCap・月の窓 sheepWindow・机 sheepDesk・目ざまし時計 sheepClock・ホットミルク sheepMilk・本棚 sheepShelf・ガーランド sheepGarland・毛糸のかご sheepYarn・スリッパ sheepSlippers。場所の一覧は js/sheep.js の SPOTS。
- 机のランプにさわると、明かりが消えて部屋が暗くなり、ガーランドの電球と、窓から床に落ちる月の光が浮かびあがります（sheepLampOff／sheepLampOn）。窓にはときどき流れ星。
- 軽さ：部屋の中で動くのは、ランプのゆらぎ・湯気・流れ星だけで、どれも小さな層だけを動かします（部屋ぜんたいを描き直さない）。廊下は、遠いときは描きません。
- 入ったとき enterSheep、出るとき backFromSheep、扉を押したとき doorSheep、廊下に来たとき enterSheepCorridor。

## 羊の間のイベント「ひみつのおひるね」（event/hitsuji-no-ma/）

羊の間に入ったとき、**禁書庫のイベント（vault-fall）を見たあと**で、**トルサの好感度が200以上**なら起こります。ベッドで寝転がっていたトルサが、見られてはずかしがるイベントです（始まる前に「見る／今は見ない」が出ます。一度見たら、パレットの「思い出」から見返せます）。

- event/hitsuji-no-ma/event.json … セリフ・表情・選択肢・さわったときのひとこと・カメラ（寝転がりの傾き rotate、映す広さ view、スマホは phone）・起こる条件（trigger）
- event/hitsuji-no-ma/hirune.svg … 絵（いまは仮の絵）。レイヤー（id）の名前を変えずに描き直せば、そのまま入れかえられます。レイヤー分けは layer-tool.html で

- event/hitsuji-no-ma/props.svg … ベッドの上の小物（枕・紺のクッション・羊のぬいぐるみ・本・毛布）。トルサの絵とは別のファイルなので、トルサの絵を入れかえても残ります。event.json の parts で prop_ ではじまるもの（さわると、ひとこと）

  - trigger の `room`（部屋に入ったとき）・`after`（そのイベントを見たあと）

## イベントの前の「見る／今は見ない」（注意書き）

event/events.js のイベント（禁書庫のイベントなど）は、始まる前に「見る／今は見ない」の画面が出ます。

- 「今は見ない」を選ぶと、そのイベントは見たことになり（もう勝手には起こりません）、パレットの「思い出」から、いつでも見られます。思い出から見るときも、同じ画面が出ます（「やめておく」で戻れます）。
- 注意書きは data/event-notice.json の `text` に書きます。default はすべてのイベント共通、events の中にイベントの名前（例: vault-fall）で書くと、そのイベントだけ上書きできます。見出し・ボタンの文字・トルサのひとこと（skipSay）も変えられます。
