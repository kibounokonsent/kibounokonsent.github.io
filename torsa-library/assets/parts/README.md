# トルサ図書館 部品SVG

館内はこのフォルダの部品を並べて組み立てています。`assets/parts-src/` には、受け取ったままの元ファイルを残してあります。

## 受け取った部品に加えた手直し

| ファイル | 手直し |
|---|---|
| window.svg | Scratch で消えていた「窓の形での切り抜き」を付け直した。周りの余白も切り詰めた |
| arch.svg | 下の方に残っていた細い棒のかけらを、表示範囲から外した |
| desk.svg | 下の方に残っていた脚のかけらを、表示範囲から外した |
| lantern.svg | 上の鎖を表示範囲から外し、宙に浮かぶ魔法のランタンにした（鎖が空から垂れて見えないように） |

ほかの部品は受け取ったまま使っています。

## 組み立て方

- 本棚は bookcase_b2.svg を6つ全部に使い、1つおきに左右反転して変化をつけています（scene.json の `decor.bookcaseFlip` で切り替え）。
- tower.svg と wall_panel.svg は、加工されていなかったので前の版のままです。
- 新しく届いた部品の使い方：
  - **tama.svg（水晶玉）** … 柱の上と、ステンドグラスの窓台の両端に置き、青く光らせています。
  - **turu.svg（ツタ）** … 柱の頭から垂らしています（何もないところから垂れて浮いて見えないように）。

## 部品を描き直すとき

- 同じ名前で上書きすれば、そのまま組み立て直されます。
- 大きさ（書き出したときの幅と高さ）が変わったときは、data/scene.json のその部品の `vb` を新しい大きさに直してください。
- `fit` がある部品（arch, grand_arch, desk, window）は、ファイル内の「左端・右端・下端」の位置で館内に合わせています。形を大きく変えたら、ファイルを渡してくれればこちらで合わせ直します。

## サイト側で描いた部品

- **end_door.svg（両端の扉）** … 本棚のいちばん外にある「まだ開かない扉」。仮の絵なので、描き直して上書きしてOKです（大きさが変わったら scene.json の `vb` を直す）。東側は左右反転して置いています。

## サイト側で足しているもの（部品には入っていない）

- ランタン・ろうそく・水晶玉・机のランプの光
- 天球儀のまわりを回る小さな星
- 月の窓の光：近づくほど、光の筋、床に落ちる色の光、光の中を舞うちり、窓まわりの明るさが強くなります
- 窓のまわりを漂う本（そのうち1冊は、ページがひとりでにめくれます）
