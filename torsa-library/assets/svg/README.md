# トルサ図書館 SVG素材

サイトの中で自動で描いていた絵を、そのまま書き出したものです。加工して差し替えられます。

## scene/ … 館内の背景（奥から順に4層）

| ファイル | サイズ（viewBox） | 中身 | 歩いたときの動き |
|---|---|---|---|
| sky.svg | 2400 × 1000 | 星空・惑星・星座・彗星 | いちばんゆっくり |
| back.svg | 2800 × 1000 | 奥の壁、月のステンドグラス、遠くの本棚 | ゆっくり |
| mid.svg | 3600 × 1000 | 本棚・柱・アーチ・ランタン・植物・天球儀・読書机・カーペット | 歩く速さ |
| front.svg | 4600 × 1000 | 手前の植物のシルエット（サイトではぼかしをかけて表示） | いちばん速い |

- sky / back / front は画面の高さに合わせて、下ぞろえで表示されます。横幅が足りないときは左右が切れます。
- back.svg は中央（x=1400）がステンドグラスの中心です。中央に置いたまま加工してください。
- mid.svg は上の空いている部分が透明で、奥の絵が透けて見えます。
- **mid.svg の注意**：手に取れる4冊の本は、サイト側でこの絵の上に重ねています。本棚の位置（x=110, 570, 1030, 2170, 2630, 3090、幅400）と、棚板の高さ（各段の下端 y=354, 470, 586, 702, 818）は変えないでください。棚に4冊ぶんの隙間があるのは、そこに本が入るためです。

### 差し替え方

data/library.json の `art` にパスを書きます。

```json
"art": { "sky": "", "back": "assets/svg/scene/back.svg", "mid": "", "front": "" }
```

空のところは今までどおり自動で描かれます。SVGのほか、PNG や WebP でも同じサイズで書き出せば使えます。

## bubbles/ … 本の吹き出しの形

round（ふつう）、spiky（驚き・興奮・怒り）、cloud（眠い・無言）、wavy（照れ・汗）。
サイトでは文章の長さに合わせて縦横に伸び縮みします。

## covers/ … 仮の表紙

今表示されている仮の表紙（300×400）です。本物の表紙は books.json の `cover.image` で差し替えられます。

---

アニメーション（星のまたたき、ランタンのゆらぎ、天球儀の回転など）は各SVGの中の `<style>` と `<animateMotion>` に入っています。
イラストソフトで開くと動きは消えることがありますが、絵としては問題なく編集できます。
