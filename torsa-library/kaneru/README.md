# カネル（好感度100のイベントと、赤い月の間）

| ファイル | 中身 |
|---|---|
| kaneru.js | プログラム（カネルの動き・イベント・廊下と赤い月の間・さわったときの圧） |
| kaneru.json | セリフと設定（いつ起こるか・イベントの流れ・部屋の名前・ささやき・トルサのセリフ・会話の箱の見た目） |
| rig.json | カネルの絵を部品に分けたもの（作り直し方は tools/kaneru/README.md） |
| moon.webp | 窓の外の赤い満月（いただいた城2.svg から月だけを取りだして、軽い絵にしたもの） |
| castle.webp | 窓の外の城（城2.svg から城だけを取りだして、軽い絵にしたもの） |
| candle_red.svg | 赤いろうそく（図書館のろうそく assets/parts/candle.svg を赤く色がえしたもの） |

※ event/ フォルダ（1つ目のイベント）とは別のフォルダです。名前もかぶっていません。

## カネルの設定で守っていること
- カネルは**テレパシーでしか話しません**。セリフはぜんぶ《 》で「心に響く声」として出て、本やトルサのような声の音（ぽぽぽ）は鳴らず、低くゆらぐ音だけが鳴ります。口も動きません。
- 極度の人間不信なので、さわろうとすると《触るな。》と圧をかけてきて、さわれません（画面のふちが暗く赤くなり、赤い輪が広がり、指先が押し返されます）。好感度もふえません。何回目かで《……二度言わせるな。》《人間が、私に触れるな。》に変わります（kaneru.json の `kaneru.touch`）。
- トルサはカネルと話したいけれど話せず、しょんぼりします（新しい表情 `sad`：耳がたれて、少しうつむく）。

## イベント（好感度100）
- 好感度が100（`trigger.affinity`）になって、本館（`trigger.hall`）に6秒（`trigger.delaySec`）いると、本館と月の窓が赤く染まり、月の窓の前にカネルが立っています。カネルの「話しかける」をさわるとイベントが始まります（勝手には始まりません。本館を出ると、いったん元にもどります）。一度見たら、来館記録をリセットするまで起こりません。パレットの「思い出」から何度でも見られます。
- 流れ：月の窓と本館が赤く染まる → 月の窓の前にカネルが現れる → 《本を探している。》→ 頭の中に本の姿が流れこむ → トルサ「その本は、見たことないねぇ」→ 背を向ける → トルサ「ここの本は、ほとんどが眠ってるんだぁ……いつか目を覚ますかもしれないねぇ」→ 《……仕方ない。》《目覚めるまで、ここにいる。》→ 西の奥に部屋をつくって消える。
- イベントのカネルは、最初からトルサの反対側（画面の左）に、トルサのほう（右）を向いて現れ、話し終えるとその場で赤い霧になって消えます。トルサと同じくらいの背の高さで、足もとの高さもそろえています（kaneru.js の `leftSpot`）。スマホでは、トルサと近くなりすぎないよう左へずらします。また、キャラクターが会話の箱に埋まらないよう、スマホでは会話の箱を画面の上に出します。
- セリフは kaneru.json の `event.steps`。`who`（torsa／kaneru／narration＝地の文／notice＝お知らせ）、`face`（トルサの表情）、`fx`（演出）を書きます。
- 会話の箱は event/events.js の箱と同じ形です。event/events.json のいちばん外の `"box"`（全イベント共通）をそのまま使い、kaneru.json の `box` で上書き、カネルのセリフのときだけ `boxKaneru`（黒い赤）を重ねます。「吹き出し非表示」（H キー）と「スキップ」もあります。

## 話しかける・カネルへの好感度
- 赤い月の間で、カネルの**まわり**（からだ以外）をさわると話しかけられます。カネルは左に出てきて、心に響く声でひとことだけ返します（kaneru.json の `kaneru.talk`。カネルへの好感度 `min` ごとに返事が変わり、ときどきトルサもひとこと）。
- 話しかけると、ひとこと返したあと《ほかに話すことでもあるのか。》と聞いてきます。タップするとほかの話を聞けて、何もしないと《もうないなら、もどるぞ。》で元の場所にもどります。何度も呼びだすと（5分に4回より多く）しばらく反応しなくなります（kaneru.json の talkAsk・talkBye・talkEnd・talkWaitSec・talkLimit）。
- カネルへの好感度は画面には出ず、とても上がりにくくしています（話しかける＋0.4・2分に1回まで、赤い月の間に来る＋1・1日1回。kaneru.json の `kaneruAffinity`）。
- 好感度が100（`patFrom`）になると、頭をなでられます。カネルは何も反応しません（はじめてのときだけトルサがびっくりします：`torsa.patKaneru`）。頭以外にさわると、これまでどおり《触るな。》。
- カネルとトルサの吹き出しがかぶらないよう、カネルが話しているあいだは、トルサの吹き出しは出ません。
- 確認用：コンソールで `__kaneruAff()` で今の値、`__kaneruAff(100)` で変更。

## 翼
- カネルの翼はふだんはしまっていて、移動するとき（左に出てくる・もどる・現れる・消える）と、さわられそうになって威嚇するときだけ、ばさっと開いて、少しして、すっと閉じます（kaneru.js の `wingOpen`。開いている長さは `wings(ミリ秒)`）。翼の音は sfx.json の `wings`。

## 赤い月の間と廊下
- イベントのあと、本館の西のはし（西の書館への扉より左）が少しずつ暗くなり、そのまま廊下になってつづきます（扉はありません）。廊下には赤いろうそくが点々と置かれていて、いちばん奥に「赤い月の間」の扉があります。廊下の長さや扉の位置は kaneru.js の `CORR`、絵は `hallCorridorHTML`。廊下の名前（画面の上に出る場所の名前）は kaneru.json の `rooms.corridor.name`。
- 廊下に入ったときのトルサのひとことは `torsa.enterCorridor`、扉をさわったときは `torsa.doorRedmoon`。
- 窓の外は「ひとつの景色」です。部屋の外に赤い夜空・月・城・遠くの丘がひとつずつあって、どの窓からも、その窓のうしろにある部分が見えます（月が2つ、城が2つにならない）。赤い月の間では、まんなかの丸窓から月、右の窓から城、左の窓からは夜空と丘。廊下では、手前の窓から月、奥の窓から城。位置と大きさは kaneru.js の `outsideScene` を呼んでいるところ（moon・castle）で変えられます。窓の外の景色は遠くにあるので、廊下を歩いたり部屋を横に見わたしたりすると、壁より遅れてゆっくり動きます（速さは `FAR`、0.25＝館内の4分の1）。
- 窓から赤い月の光が差しこみ、床に窓わくのかげが落ちます。赤い月の間のカネルは窓を背にしているので少し逆光で暗く、話すために出てくるときはふつうの明るさになります。
- 窓の外の景色・壁・光は、動かない絵として一度だけ描き、遠くの景色の層だけを動かしているので軽く動きます。
- ろうそくは、すべて図書館のろうそくを赤く色がえした絵（candle_red.svg）です。
- 赤い月の間：黒が基調の部屋。まんなかに赤い満月の丸窓、左右の窓、燭台と暗い赤のカーテン。カネルは丸窓の前にたたずんでいて、トルサと同じように部品で動きます（呼吸・翼・マント・髪・耳・まばたき）。
- 赤い月の間の「もどる」で、西の書館の廊下にもどります。転送（パレット）にも「赤い月の間」が出ます（イベントのあとだけ）。
- 赤い月の間でカネルが話すとき（さわろうとしたとき・ときどきもれる心の声 `kaneru.murmur`、出る確率 `murmurChance`）は、カネルが左へ出てきて右を向き、黒い赤の吹き出しで話します。話し終えると元の場所にもどります。

## 確認用
- ブラウザのコンソールで `__affinity(100)` → 本館にいれば数秒でイベントが起こります。
- URL の最後に `?kaneru` を付けて開くと、好感度に関係なく、入館して本館に少しいるとイベントが起こります（例：`index.html?kaneru`）。
