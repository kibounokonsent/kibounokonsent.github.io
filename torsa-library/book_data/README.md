# book_data（寄贈された本のフォルダ）

寄贈の間（`donate.html`）で作られた「寄贈本_○○.json」を、このフォルダに入れるだけで、
図書館を開いたときに書架に並びます。棚の場所は、空いているところに自動で決まります。

## 入れかた

1. 受け取った「寄贈本_○○.json」を、このフォルダにそのまま入れる
2. 図書館を開きなおす（書架と蔵書目録に出てきます）

本をしまうときは、そのファイルをこのフォルダから出すだけです。

## いまの寄贈本（txt）の中身

寄贈の間が作る「寄贈本_○○.txt」の中身は、`data/works.json` と `data/books.json` に**そのまま貼れる JSON** です
（棚の置き場所も、いまの `data/books.json` の空きを見て入っています）。使いかたは、次のどちらかです（**両方はしないでください**。同じ本が2冊並びます）。

- このフォルダに入れる（上の「入れかた」のとおり）
- txt の中の2つの JSON を、`data/works.json` の `"works"` の配列と、`data/books.json` の `"books"` の配列の、それぞれ最後に `,` を付けて貼る

前の形（「■題名」「■表紙」…と書いてある txt）や `.json` も、これまでどおり読めます。

## list.json について

たいていのサーバー（自分のパソコンで動かす python のサーバー、GitHub Pages など）では、
このフォルダの中身を自動で見つけるので、何もしなくて大丈夫です。

フォルダの中身を見せないサーバーに置いたときだけ、`list.json` にファイル名を書き足してください。

```
["寄贈本_星降る夜の物語.json", "寄贈本_我、この地を守りし武士なり.json"]
```

## 中身を少し直したいとき

寄贈の間の「綴じた本を開いて直す」でファイルを開くと、続きから直して綴じなおせます。
（ファイルの中の、決まった形の値だけを使います。ほかの書き込みは無視されます。）

## 挿絵のある本

挿絵のある本は、寄贈の間で `寄贈本_○○.zip` ができます。zip を解凍して、中の

- `寄贈本_○○.txt`
- `book_images` フォルダ

を、**どちらも** この `book_data` フォルダに入れてください（`book_data/book_images/（整理番号）/` に画像が入る形です）。
しまうときは、txt と、`book_images` の中のその本のフォルダを出します。
