# book_data（寄贈された本のフォルダ）

寄贈の間（`donate.html`）で作られた「寄贈本_○○.json」を、このフォルダに入れるだけで、
図書館を開いたときに書架に並びます。棚の場所は、空いているところに自動で決まります。

## 入れかた

1. 受け取った「寄贈本_○○.json」を、このフォルダにそのまま入れる
2. 図書館を開きなおす（書架と蔵書目録に出てきます）

本をしまうときは、そのファイルをこのフォルダから出すだけです。

## list.json について

たいていのサーバー（自分のパソコンで動かす python のサーバー、GitHub Pages など）では、
このフォルダの中身を自動で見つけるので、何もしなくて大丈夫です。

フォルダの中身を見せないサーバーに置いたときだけ、`list.json` にファイル名を書き足してください。

```
["寄贈本_星降る夜の物語.json", "寄贈本_我、この地を守りし武士なり.json"]
```

## 中身を少し直したいとき

寄贈の間の「綴じた本を開いて直す」でファイルを開くと、続きから直して綴じなおせます。
（ファイルの中の、決まった形の値だけを使います。ほかの書き込みは無視されます。）
