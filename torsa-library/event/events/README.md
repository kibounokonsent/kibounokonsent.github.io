# トルサのイベント

全画面に一枚絵が出て、トルサが部品ごとに Live2D のように動くイベントです。いまは禁書庫の「禁書庫でころぶ」が1つあります。

1つのイベントは、次の2つでできています。

| もの | 場所 | 中身 |
|---|---|---|
| 絵（1ファイル） | `event/events/vault-fall.svg` | 部品ごとにレイヤーを分けた絵 |
| 設定 | `event/events.json` の `events["vault-fall"]` | セリフ・表情・いつ起こるか・部品の動かし方・さわったときの反応 |

プログラムは `event/events.js` です（ふだんは開かなくても大丈夫です）。

## 見かた

- **ふつうに** … 禁書庫に入って8秒ほどたつと起こります（一度見たら、来館記録をリセットするまで起こりません）。
- **もう一度見る** … 右上の「パレット」→「思い出」から、見たことのあるイベントを何度でも見られます。
- **すぐ見る（確認用）** … URL の最後に `?event=vault-fall` を付けて開き、入館すると始まります。ブラウザのコンソールで `__event("vault-fall")` でも始まります。`event-preview.html` は、イベントだけを確認するページです。

## イベント中にできること

- 会話の箱か、トルサ以外の場所をクリック（タップ）すると会話が進みます。Enter・スペースでも進みます。
- **トルサにさわる** … 頭・耳・角・襟・葉っぱ・からだ・腰で反応がちがいます（頭は、押したままこするとなでなで）。腰は、からだの中のベルトのあたりです。そのときのひとことは `touch` に書きます。
- **吹き出し非表示** … 会話の箱を消して絵だけを見られます（H キーでも切りかえ）。トルサ以外の場所をタップするともどります。
- **スキップ** … イベントをとばします。

## 絵を描き直すとき

`vault-fall.svg` は、いただいた絵と同じ大きさのキャンバスに、部品ごとのレイヤーが並んでいます。Inkscape などで開くと、レイヤーの一覧に「leaf_back 奥の葉」「ear_l 耳（左）」のように名前が出ます。

- レイヤーの中身は自由に描き直して大丈夫です。位置もそのまま合います（絵がある範囲はサイトが自動で調べます）。
- **レイヤーの id（leaf_back など）は変えないでください。** サイトは id で部品を探しています。
- 部品を増やすときは、レイヤーを1つ足して id を付け、`event/events.json` の `parts` に1行足します（`{ "id": "新しいid", "bone": "head", "z": 1 }`）。
- 汗（fx_sweat）と照れ線（fx_lines）は、イベント用に描き足したレイヤーです。

| レイヤー | 中身 | 動き |
|---|---|---|
| leaf_back / leaf_right / leaf_top / leaf_left | 紫の葉（奥1枚・手前3枚） | ゆらゆら・うねうね・巻きつく・ほどける |
| coat_back / shirt / cape_* | 腕・上着・マント | 呼吸・ぷるぷる |
| legs | 脚と靴 | 転んだときのはずみ |
| hair_back / hair_front / lock_* / ahoge | 髪 | 頭より少し遅れてゆれる |
| face / blush / eye_l / eye_r | 顔・頬・目 | 目をぎゅっ、頬の赤みが表情で変わる |
| ear_l / ear_r / horn_l / horn_r | 耳・角 | 耳がたれる・ぴくっ |
| collar / brooch | 襟とブローチ | 顔をうずめると持ち上がる |

## 設定（event/events.json）

- `trigger` … いつ起こるか。`hall`（棟）、`delaySec`（何秒後）、`minAffinity`（好感度がいくつ以上で）、`once`（一度だけ）。
- `camera` … トルサの位置と角度。`anchor`（目印の点＝ブローチ）を画面の `at` に置き、`view` の広さが入る大きさにして、`rotate` 度かたむけます。スマホの縦画面は `phone` の値を使います。
- `lines` … 会話。`face`（表情）・`leaves`（葉の動き：rest／wiggle／tight／loose）・`shake`（画面のゆれ）・`sfx`（効果音）。`speaker` を `""` にすると地の文。
- `faces` … 表情。頬の赤み・照れ線・汗・目のつむり方・襟にうずめる量・震え・頭のかたむき。
- `touch` … さわったときのひとことと効果音。
- `secrets` … 小ネタ。部品の id（葉なら `leaf_back` など）ごとに、さわったときの反応を、ふつうの葉とは別にできます。`lines` は1回目・2回目…と順番に出て、最後まで出たら `repeat` からランダムに出ます。`sfx`（効果音）、`jump`（トルサが跳ねる高さ）、`leafPoke`（葉のゆれの大きさ。ふつうは 3.5）も決められます。いまは一番下の葉（`leaf_back`）だけです。スマホの縦画面では下まで映りますが、パソコンの横長画面では、この葉はほとんど画面の外です。
- `zones` … からだの中の、さらにさわれる場所。`waist`（腰）を、絵の座標の四角 `[x, y, はば, たかさ]` で書きます。「からだ」の部品のうち、この四角の中にさわったときだけ `touch.waist` の反応になります。絵を描き直して位置がずれたら、この数字を直します。
- `after` … イベントのあと、館内にもどったときのトルサのひとこと。
- `bg`・`box` … うしろの色・会話の箱の色。

## 絵をまるごと作り直すとき

いただいた元の絵（`tools/event/src/vault-fall_original.svg`）から、部品ごとのレイヤーに分け直すプログラムがあります。

```
python3 tools/event/split_event.py tools/event/src/vault-fall_original.svg event/events/vault-fall.svg
```

元の絵のグループの順番を変えたときは、`tools/event/split_event.py` の `PARTS` の表を合わせて直します。
