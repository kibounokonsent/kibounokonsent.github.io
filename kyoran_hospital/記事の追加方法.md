# 記事の追加方法

狂乱病院 ARCHIVE に記事を足すための手順書です。
**触るのは `js/data/` の中だけ**。`js/core/app.js`（本体）と `css/style.css`（見た目）は触らなくて大丈夫です。

---

## 0. 準備

- テキストエディタを1つ用意します（VS Code がおすすめ。メモ帳でも可）。
- ファイルは **UTF-8** で保存してください（VS Code なら最初から UTF-8）。
- 確認は `index.html` をブラウザで開くだけ。保存したら **再読み込み（F5）** で反映されます。

---

## 1. 最短手順（3ステップ）

### ① どのファイルに書くか決める

記事の種類ごとに、書くファイルが決まっています。

| 書きたいもの | ファイル | `cat` | 一覧での見た目 |
|---|---|---|---|
| 作品全体の話 | `js/data/articles/overview.js` | `'overview'` | ファイル |
| 主人公・所長など主要人物 | `js/data/articles/people.js` | `'people'` ＋ `group: 'main'` | 大きなプロフィール |
| 医師・職員 | `js/data/articles/staff.js` | `'people'` ＋ `group: 'staff'` | 職員証 |
| 入院患者 | `js/data/articles/patients.js` | `'people'` ＋ `group: 'patients'` | カルテ |
| オルドレンジ | `js/data/articles/oldrange.js` | `'oldrange'` | ファイル |
| 病院の部屋・区画 | `js/data/articles/facility.js` | `'facility'` | 扉 |
| ゲームシステム | `js/data/articles/system.js` | `'system'` | ファイル |
| 用語 | `js/data/articles/glossary.js` | `'glossary'` | ファイル |
| ルート（結末） | `js/data/articles/routes.js` | `'routes'` | ファイル |
| 精神ゲージ 0 のときだけの記事 | `js/data/articles/madness.js` | 好きなカテゴリー | そのカテゴリーの見た目 |

### ② 記事を1件コピーして貼る

ファイルの中はこういう形になっています。

```js
ARTICLES.push(
  {
    …1件目の記事…
  },          ← 記事と記事のあいだに「,」（カンマ）

  {
    …2件目の記事…
  }           ← 最後の記事の後ろはカンマなしでもOK
);
```

**最後の記事の `}` の後ろに `,` を打ち、** その下に新しい記事 `{ … }` を貼ります。
いちばん簡単な記事はこれだけです：

```js
  {
    id: 'kitchen',
    cat: 'facility',
    title: '厨房',
    summary: '地下にある厨房。',
    updated: '2026-10-02',
    sections: [
      { h: '概要', body: [
        '地下にある厨房。',
      ] },
    ],
  },
```

### ③ 保存して、ブラウザを再読み込み

これで、カテゴリーの一覧・トップの「最近更新」・全記録・検索に自動で出ます。
`index.html` を書き換える必要はありません。

---

## 2. 項目の意味

| 項目 | 必須 | 書き方・意味 |
|---|---|---|
| `id` | ◯ | 半角英数字とハイフンだけ（例 `kise` `oldrange-mantis`）。**他の記事と重複しないこと**。URL になります |
| `cat` | ◯ | 上の表のカテゴリー |
| `title` | ◯ | 記事のタイトル |
| `summary` | ◯ | 一覧のカードに出る短い説明（1〜2文） |
| `updated` | ◯ | 更新日 `'2026-10-02'`。新しい順に並びます |
| `sections` | ◯ | 本文（下の「3. 本文の書き方」） |
| `group` | 人物のみ | `'main'`／`'staff'`／`'patients'` |
| `kana` | | 読みがな。検索にも使われます |
| `en` | | 英字ラベル（例 `'OLD RANGENIUM'`） |
| `image` | | 画像のパス（下の「5. 画像」） |
| `info` | | 右側の「診療録」カードの項目 |
| `keywords` | | 検索用の別名 `['オールド', '所長']` |
| `related` | | 関連記事の `id` を並べる `['kise', 'oldrange']` |
| `stamp` | | カルテ・職員証の判子／扉の札（例 `'隔離'` `'使用中'`） |
| `room` | 施設のみ | 扉の部屋番号（例 `'B4-01'`） |
| `spoiler` | | `true` でネタバレ記事 |
| `madness` | | `true` で精神ゲージ 0 のときだけ存在する記事 |

### info（診療録カード）

```js
    info: [
      ['分類', '生物兵器'],
      ['体長', '約5m'],
      ['正体', '……', true],   // 3つ目に true を書くと、この行だけネタバレ
    ],
```

カルテ（患者）と職員証（医師・職員）には、`info` の**最初の2〜3行**が一覧にも表示されます。患者なら `['病名', …]` `['病室', …]` を先頭に置くと「カルテらしく」なります。

---

## 3. 本文の書き方

`sections` は「見出し＋中身」の並びです。

```js
    sections: [
      {
        h: '概要',              // 見出し
        body: [                 // 中身（上から順に表示）
          'ふつうの段落。',
          '2つ目の段落。',
        ],
      },
      {
        h: '能力',
        body: [ … ],
      },
    ],
```

見出しが3つ以上あると、自動で目次が付きます。

### 文の中で使える書き方

| 書き方 | 表示 |
|---|---|
| `[[kise]]` | 記事「木瀬」へのリンク（`id` を書く） |
| `[[kise\|主人公]]` | 表示する文字を変えたリンク |
| `**太字**` | 太字 |
| `==血文字==` | 赤く光る強調 |
| `{{黒塗り}}` | 黒塗り（マウスを乗せると読める。覗くと精神ゲージが減る） |
| `\|\|ネタバレ\|\|` | ネタバレなしモードでは消える文字 |
| `\n` | 改行（記録・警告ブロックの中で使う） |

### ブロック（body の中に置ける部品）

```js
          { type: 'list',   items: ['箇条書き1', '箇条書き2'] },
          { type: 'olist',  items: ['番号付き1', '番号付き2'] },
          { type: 'warn',   title: '警告', text: '赤い警告。' },
          { type: 'note',   title: 'メモ', text: '補足メモ。' },
          { type: 'record', title: '診療記録 No.012', text: 'カルテ風の記録。\n改行もできる。' },
          { type: 'quote',  text: '台詞や引用。', by: '発言者' },
          { type: 'table',  head: ['項目', '内容'], rows: [['体長', '約5m'], ['瞳', '赤']] },
          { type: 'image',  src: 'assets/images/oldrange/mantis.svg', caption: '画像の説明' },
          { type: 'flow',   items: ['一段目', '二段目', '三段目'] },   // 縦の流れ図
```

## 4. 種類別のお手本

### 入院患者（カルテ）— `patients.js`

```js
  {
    id: 'patient-eyeball',
    cat: 'people',
    group: 'patients',
    stamp: '隔離',
    title: '患者名',
    kana: 'かんじゃめい',
    summary: '所見欄に出る短い説明。',
    updated: '2026-10-02',
    info: [
      ['病名', '……'],
      ['病室', '303号室'],
      ['担当医', '[[mad-doctors]]'],
    ],
    sections: [
      { h: '概要', body: ['……'] },
      { h: '経過', body: [
        { type: 'record', title: '診療記録 No.001', text: '……' },
      ] },
    ],
    related: ['mad-patients'],
  },
```

### 医師・職員（職員証）— `staff.js`

```js
  {
    id: 'doctor-xxx',
    cat: 'people',
    group: 'staff',
    title: '医師の名前',
    kana: 'よみ',
    summary: '短い説明。',
    updated: '2026-10-02',
    image: 'assets/images/staff/doctor-xxx.png',
    info: [
      ['役職', '外科医'],
      ['嗜好', '内臓'],
    ],
    sections: [ { h: '概要', body: ['……'] } ],
  },
```

### 病院施設（扉）— `facility.js`

```js
  {
    id: 'operating-room-1',
    cat: 'facility',
    room: 'B4-01',
    stamp: '使用中',
    title: '第一手術室',
    summary: '扉を開けると見える説明。',
    updated: '2026-10-02',
    sections: [ { h: '概要', body: ['……'] } ],
  },
```

`facility.js` は今は空っぽで、中身はこうなっています。

```js
ARTICLES.push(
);
```

この `(` と `)` のあいだに `{ … }` を貼ってください（1件目なのでカンマは不要）。

### オルドレンジ — `oldrange.js`

`oldrange-mantis`（カマキリ型）がお手本です。そのままコピーして書き換えるのがいちばん早いです。

## 5. 画像を入れる

1. 画像を `assets/images/` の中の、カテゴリーごとのフォルダに置きます
   （`characters/` `staff/` `patients/` `oldrange/` `facility/` `system/` `routes/`）。
2. 記事に `image: 'assets/images/oldrange/xxx.svg',` と書きます。
   - 一覧のサムネイル、記事右の診療録カードに表示されます。
3. 本文の途中に入れたいときは `{ type: 'image', src: '…', caption: '…' }`。

- PNG・JPG・SVG・WebP が使えます。
- ファイル名は**半角英数字**がおすすめです（日本語名だと環境によって読めないことがあります）。
- 黒っぽい画像でも見えるよう、画像の後ろは自動で「標本ライト」で照らされます。

## 6. ネタバレ・精神ゲージ 0 の記事

| やりたいこと | 書き方 |
|---|---|
| 記事まるごとネタバレ | 記事に `spoiler: true,` |
| 見出し（節）だけネタバレ | `{ h: '真相', spoiler: true, body: [ … ] }` |
| ブロックだけネタバレ | `{ type: 'warn', spoiler: true, text: '…' }` |
| 表の1行だけネタバレ | `rows` の中で `{ cells: ['A', 'B'], spoiler: true }` |
| 診療録の1行だけネタバレ | `['目的', '…', true]` |
| 文の一部だけネタバレ | `\|\|この部分\|\|` |
| 精神ゲージ 0 のときだけ現れる | 記事に `madness: true,` |

ネタバレなしモードでは、これらは一覧・検索・リンクのどこにも出てきません。
精神ゲージ 0 の記事は、0 の間は見やすく、古い記事は崩れていきます。

## 7. 確認のしかた

ブラウザの**開発者ツール**（F12 キー）→「Console（コンソール）」タブを開いて再読み込みすると、書き間違いを教えてくれます。

| 出てくる表示 | 意味 |
|---|---|
| `[狂乱病院] 記事IDが重複しています: xxx` | 同じ `id` の記事が2つある |
| `[狂乱病院] 存在しないカテゴリー: xxx` | `cat` の書き間違い |
| `[狂乱病院] リンク先がありません: xxx` | `[[xxx]]` の id が存在しない（ページ上では取り消し線になる） |
| `Uncaught SyntaxError` | カンマ・カッコ・引用符の書き間違い（下の「8」） |

コンソールでは、次の確認用コマンドも使えます。

| 打つもの | 動き |
|---|---|
| `khSanity(0)` | 精神ゲージを 0 にする（0 の記事・崩れ方の確認） |
| `khSanity(100)` | 精神ゲージを 100 に戻す |
| `khJumpscare()` | ジャンプスケアだけを再生する（音が出ます） |

ネタバレモードを最初の選択画面からやり直したいときは、コンソールで `localStorage.clear()` と打って再読み込みしてください。

## 8. よくある失敗

**ある記事ファイルの記事がまるごと消えた** → そのファイルのどこかに書き間違いがあり、ファイル全体が読めなくなっています（他のファイルの記事は無事です）。直前に書いた記事を見直してください。よくある原因は次の4つです。

1. **記事と記事のあいだのカンマ忘れ**
   ```js
     }      ← ここに「,」が要る
     {
   ```
2. **文字の中の `'`（シングルクォート）**
   `'木瀬's room'` のように文字の中に `'` があると壊れます。`"木瀬's room"` とダブルクォートで囲むか、全角の `’` を使ってください。
3. **全角の記号**
   `：` `，` `（` `）` `｛` など、**記号の部分**が全角になっていると動きません（文字の中身は全角でOK）。
4. **カッコの閉じ忘れ**
   `{` と `}`、`[` と `]` の数が合っているか確認してください。VS Code ならカッコをクリックすると対になる相手が光ります。

**記事は出るのに一覧に出ない** → `cat` の綴り違い、またはネタバレ記事をネタバレなしモードで見ている、のどちらかです。

**画像が出ない** → パスの綴り（大文字・小文字も区別されます）とファイルの場所を確認してください。

## 9. カテゴリー（病棟）を増やしたいとき

1. `js/data/categories.js` に1行追加します。
   ```js
     { id: 'items', ward: 'B8', name: '所持品', en: 'ITEMS', icon: 'book', desc: '説明。' },
   ```
   - `icon`：`cross` `person` `scalpel` `bed` `claw` `door` `pulse` `branch` `book`
   - `layout`：一覧の見た目 `files`（標準）`profile` `badge` `karte` `doors`
   - `spoiler: true` で病棟ごとネタバレ扱い（末尾に置くと、ネタバレなしモードで病棟番号に欠番が出ません）
2. `js/data/articles/items.js` を作り、`ARTICLES.push( … );` の形で記事を書きます。
3. `index.html` の「▼ 記事データ」の欄に1行足します。
   ```html
   <script src="js/data/articles/items.js"></script>
   ```

新しい**ファイル**を作ったときだけ 3 が必要です。既存のファイルに記事を足すだけなら `index.html` は触りません。
