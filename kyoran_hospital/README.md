# 狂乱病院 ARCHIVE

『狂乱病院』の設定資料サイト。HTML / CSS / JS だけで動きます（サーバー不要・`index.html` をブラウザで開くだけ）。

```
kyoran_hospital/
├─ index.html
├─ 記事の追加方法.md       … ★ 記事の足し方（手順・お手本・よくある失敗）
├─ css/style.css            … 見た目（色は :root の変数で変更）
├─ js/
│  ├─ core/app.js           … 本体（基本的に触らない）
│  └─ data/
│     ├─ config.js          … サイト名・ロゴ・演出のON/OFF・院内放送
│     ├─ categories.js      … カテゴリー（病棟）一覧
│     └─ articles/
│        ├─ _TEMPLATE.js    … 記事の書き方見本（読み込まれません）
│        ├─ overview.js     … B1 作品概要
│        ├─ people.js       … B2 院内名簿／主要人物
│        ├─ staff.js        … B2 院内名簿／医師・職員
│        ├─ patients.js     … B2 院内名簿／入院患者
│        ├─ oldrange.js     … B3 オルドレンジ
│        ├─ facility.js     … B4 病院施設（まだ空）
│        ├─ system.js       … B5 システム
│        ├─ glossary.js     … B6 用語集
│        ├─ routes.js       … B7 ルート（ネタバレ病棟）
│        └─ madness.js      … 精神ゲージ 0 のときだけの記事
└─ assets/images/
   ├─ logo/                 … ロゴ画像を置く場所
   └─ characters/ staff/ patients/ oldrange/ facility/ system/ routes/
```

---

> **記事の足し方は `記事の追加方法.md` に、手順・お手本・よくある失敗までまとめてあります。** 以下は概要です。

## 記事を追加する（いちばんよく使う作業）

1. `js/data/articles/_TEMPLATE.js` の `{ … }` をコピー
2. 追加したいカテゴリーのファイル（例：`oldrange.js`）を開く
3. `ARTICLES.push(` の中、最後の記事の `}` の後ろに **`,`（カンマ）** を付けて貼り付ける
4. `id` `cat` `title` などを書き換えて保存 → 終わり

これだけで、カテゴリーページ・トップの「最近更新された記録」・全記録・検索・関連項目に自動で出ます。

### 本文で使える書き方

| 書き方 | 表示 |
|---|---|
| `[[kise]]` | 記事「木瀬」へのリンク |
| `[[kise\|主人公]]` | 表示名を変えたリンク |
| `**太字**` | 太字 |
| `==血文字==` | 赤く光る強調 |
| `{{黒塗り}}` | 黒塗り（マウスを乗せると読める） |

### 本文ブロック

`list`（箇条書き）／`olist`（番号付き）／`warn`（赤い警告）／`note`（メモ）／`record`（カルテ風の記録）／`quote`（台詞・引用）／`table`（表）／`image`（画像）／`flow`（縦の流れ図）。書き方は `_TEMPLATE.js` 参照。

### その他の項目

- `spoiler: true` … ネタバレ記事（下の「ネタバレモード」参照）
- `image` … サムネイル＆診療録（右のカード）の画像
- `info` … 診療録カードの項目 `['ラベル', '値']`
- `related` … 関連項目に出す記事の id
- `updated` … 更新日。新しい順に並ぶ

リンク先 id の書き間違いはブラウザのコンソールに警告が出ます（ページ上では取り消し線で表示）。

### 人物・施設の追加

人物はすべて `cat: 'people'`（院内名簿）にまとめ、`group` で欄を分けます。欄ごとに見た目が変わります。

| group | 欄 | 見た目 | 書くファイル |
|---|---|---|---|
| `main` | 主要人物 | 大きなプロフィール | people.js |
| `staff` | 医師・職員 | 職員証 | staff.js |
| `patients` | 入院患者 | カルテ（記事ページの診療録もカルテ紙になる） | patients.js |

職員証・カルテには `info` の最初の2〜3項目が載ります（例：`['病名', '…']`, `['病室', '…']`）。

病院施設は `cat: 'facility'`。扉が並ぶ廊下として表示され、マウスを乗せると扉が開いて概要が見えます。`room: 'B4-01'` で扉の部屋番号、`stamp: '使用中'` で扉の札を指定できます。記事がない間は「施錠中」の扉が並びます。

`stamp` はカルテ（判子）・職員証（判子）・扉（札）・主要人物で使えます。`spoiler: true` の記事には自動で「機密」が押されます。

一覧の見た目は `categories.js` の `layout`（`files` / `profile` / `badge` / `karte` / `doors`）で、どのカテゴリーにも付け替えられます。

## ネタバレモード

初回アクセス時に、入院区分として2つから選びます（選択はブラウザに保存され、ヘッダーの目のボタンでいつでも切り替え可）。

| 区分 | モード | 内容 |
|---|---|---|
| 一般外来 | ネタバレなし（初見向け） | ネタバレ部分を**完全に除外**。一覧・件数・検索・関連項目・前後ページ・FILE番号のどこにも痕跡を残さない。URL直打ちでも「存在しない記録」と表示 |
| 特別病棟 | ネタバレあり（完全資料集） | すべて表示。全ページ上部に「ネタバレあります！」の注意帯、ネタバレ部分には赤いラベル |

ネタバレの指定は5段階の細かさで書けます。

| 単位 | 書き方 |
|---|---|
| カテゴリーごと | `categories.js` で `spoiler: true`（今は「ルート」病棟） |
| 記事ごと | 記事に `spoiler: true` |
| 節（見出し）ごと | `sections` の中の `{ h: '…', spoiler: true, body: [...] }` |
| ブロック・表の行 | `{ type: 'table', spoiler: true, … }` ／ `{ cells: ['A','B'], spoiler: true }` |
| 情報カードの行 | `['目的', '…', true]` |
| 文の一部 | `||ここだけ||` |

ネタバレなしモードでは、ネタバレ記事へのリンク `[[route-true]]` はリンクが外れて文字だけになります。リンクの文字自体も隠したいときは `||[[route-true]]||` のように囲んでください。

ルート病棟を最後（B7）に置いているのは、ネタバレなしモードで病棟番号に欠番が出ないようにするためです。ネタバレ病棟を増やすときも、末尾に足すのがおすすめです。

## ロゴを入れる

1. ロゴ画像を `assets/images/logo/` に置く（例：`logo.png`）
2. `js/data/config.js` の `logo: ''` を `logo: 'assets/images/logo/logo.png'` に変更

ヘッダー・トップ・入院同意画面のすべてがロゴ画像に置き換わります。ヘッダー用に横長の小さい版を使う場合は `logoSmall` も指定。空欄に戻せば文字タイトルに戻ります。

### トップのSVGロゴ（グリッチ・文字化け対応）

`config.js` の `heroLogo: 'assets/images/logo/logo.svg'` が、トップのロゴ（上の英字・タイトル・下の英字）です。

- **差し替え**：`assets/images/logo/logo.svg` を同じ名前で上書きするだけ。
- **演出を効かせる条件**：SVG内の id を `logo.svg` 冒頭のコメントどおりに付ける（`#kh-title` と `#kh-g1`〜`#kh-g4`、化け字は `#kh-alt-1-1` など）。id が無くても表示はされますが、グリッチ・文字化けは働きません。
- **赤いずれ・光・グリッチ**はCSSが付けるので、SVGには入れなくてOK。
- **廃病院の壁の質感**：`#kh-title` と `#kh-alts` の `filter="url(#kh-wall)"` が、剥がれ・ひび・汚れ・錆を付けています。外したいときはこの2か所の `filter` 属性を消すだけ。
- **血しぶき**：`#kh-blood`（`data-role="fx"`）にまとめてあります。`mask="url(#kh-blood-mask)"` で文字の形に切り抜かれています（外すと外へはみ出します）。消すときはこのグループを削除。赤ずれ・グリッチ用の複製には含まれません。
- **赤い下ずれ**はSVGに入れず、CSS（`.hl-shadow`）が付けます。文字化けで字が変わっても追従します。
- **文字化け**は精神ゲージが減ると、化け字（現在は 狙・乳・痛・陰）に一瞬だけ入れ替わります。同じ文字目に `#kh-alt-1-2` のように足すと、ランダムに選ばれます。
- ブラウザにファイルを直接ドラッグして開いた場合（`file://`）は、静的な画像表示になります（演出なし）。Webサイトとして公開した状態、またはローカルサーバー経由なら演出が動きます。
- 従来の文字タイトルに戻すには `heroLogo: ''`。

## カテゴリーを増やす

1. `categories.js` に1行追加（`icon` は cross / person / scalpel / bed / claw / door / pulse / branch / book から選択、`layout` で一覧の見た目を選択）
2. `js/data/articles/` に新しいファイルを作り、`ARTICLES.push( … );` で記事を書く
3. `index.html` の「▼ 記事データ」に `<script src="js/data/articles/新ファイル.js"></script>` を1行追加

## 演出

`config.js` の `effects` で ON/OFF・数値を調整できます。

- **entryGate** … 初回だけ出る夜間受付。二つの扉（一般外来＝ネタバレなし／特別病棟＝ネタバレあり）から選ぶと、扉が開いて中へ吸い込まれる（「帰る」を押しても帰れない）。false にすると選択画面を出さず `defaultMode`（'safe' か 'spoiler'）で始まる
- **whispers** … 背景にまれに浮かぶ囁き（文言は `whisperTexts`）
- **notices** … トップを流れる院内放送

### 精神ゲージ

| 減り方 | 設定 |
|---|---|
| 記事を初めて開く | `sanityLoss`（6） |
| 記事を読んでいるあいだ、じわじわ | `sanityDrain`（15秒ごとに1） |
| 黒塗り `{{…}}` を覗く（1か所1回） | `redactLoss`（3） |

ゲージが減るほど画面が荒れていきます（`corruption: false` で止まる）。

| ゲージ | 起きること |
|---|---|
| 60〜100 | 平常 |
| 30〜59 | ときどき本文が一瞬**文字化け**、まれに**ノイズ**（画面が裂けて色がずれる）、蛍光灯のちらつきが速くなる |
| 1〜29 | 文字化け・ノイズが頻繁に。**責める言葉**が画面に一瞬チラつく（文言は `blameTexts`）。ゲージの数字も壊れる |
| 0（狂気） | すべてが最大。背景が赤く染まり、**0 のときだけの記事**が現れる |

0（狂気）になると、さらに：画面を血が伝い、心拍のように画面が脈打ち、古い記事は文字が恒常的に壊れ・ぼやけ・傾く（`zeroRot`）。0 のときだけの記事は逆にくっきり読みやすくなる。

ゲージをクリックすると：

- **精神安定剤を投与** … 自分の腕に注射する演出のあと、ゲージが減らなくなる（もう一度押すと解除）
- **正気に戻る** … 鎮静剤の注射のあと 100 に回復。0 のときだけの記事は消え、壊した記事も元に戻る

### 精神ゲージ 0：記事の破壊とジャンプスケア

0 のあいだ、古い記事（一覧のカード・カルテ・職員証・扉、記事ページ本体）は**叩くと壊れる**ようになります（`destroy`）。

- 叩くたびに血が飛び、ひび・血の染みが増え、`destroyHits` 回（標準 7 回）で砕けて「破壊された記録」になる
- 左下に残りの記録数が出る
- すべて壊すと、一瞬の静寂のあと**悲鳴とともにオルドレンジが画面いっぱいに現れる**（`jumpscare`、画像は `config.js` の `jumpscareImages`。`focus` で顔の位置を指定するとそこへズーム）
- そのあと「正気に戻る」か「このまま狂っている」を選べる
- 0 のときだけの記事は壊せない（普通に開ける）

効果音（叩く音・扉のきしみ・注射・悲鳴）はブラウザ内で合成しているので、音声ファイルは不要です（`sound`／`soundVolume`）。

画面の荒れ・点滅そのものを止めたい閲覧者は、フッターの「演出：OFF」で全演出が止まります（OSの「視差効果を減らす」設定でも自動停止）。

### 0 のときだけ現れる記事

記事に `madness: true` を付けるだけ。ゲージ 0 のあいだだけ一覧・検索・リンクに現れ、それ以外は URL を直接開いても「存在しない記録」になります。どのカテゴリーにも置けて、`spoiler: true` とも併用できます。サンプルとして `articles/madness.js` に「あなた」というカルテを入れてあります（差し替え・削除OK）。

作者が確認するときは、ブラウザの開発者ツールのコンソールで `khSanity(0)` と打つとゲージを直接 0 にできます（`khSanity(100)` で戻る）。`khJumpscare()` でジャンプスケアだけを再生できます。
