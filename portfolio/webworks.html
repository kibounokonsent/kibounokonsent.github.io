MOON CORE

MOON CORE ARCHIVE

科学技術やAI、生体工学が発展した未来を舞台とする オリジナルSF世界観作品の設定資料集サイトです。

HTML・CSS・JavaScriptを使用し、 カテゴリー分類、記事表示、検索機能などを実装しています。

制作当初から現在の形だったわけではなく、 数々の試行錯誤を重ねながら、現在のサイトへと発展してきました。 カテゴリー数を12に固定して情報を整理したり、 より多くの記事を見やすく確認できるよう全記事一覧を追加したり、 ヘッダーを追加してサイト全体を移動しやすくするなど、 実際に使用しながら必要な機能や構成を考え、改善を続けています。

使用技術

  • HTML
  • CSS
  • JavaScript

制作について

現在も継続して改善や資料追加を行っています。
新しい資料が追加されるたびに、情報量が増えても 見やすく、使いやすいサイトになるよう更新しています。

制作方法

Webサイトの制作（HTML・CSS・JavaScript）にはAIを活用しています。

MOON CORE TRPG

MOON CORE TRPG

MOON COREの世界観をもとに制作している、 オリジナルTRPGのプレイ用Webサイトです。

制作初期は、キャラクターシートを作成するための キャラクターシートジェネレーターとして制作を始めました。

その後、制作を進める中でルールブックや戦闘ルール、 キャラクター作成ルールなどの機能を追加し、 ルールを確認しながらゲームを進行できるサイトへと発展しました。

「見やすく、わかりやすく、ゲームを回すために必要な情報を このサイトだけで確認できること」を目指して、 現在も構成や機能の改善を続けています。

  • JavaScript

Eclipse Lab

ECLIPSE LAB ARCHIVE

架空の研究施設「Eclipse Lab」を舞台とした、 アーカイブ探索型のゲーム作品です。

プレイヤーは施設から残されたArchiveへアクセスし、 様々な記録を読み進めながら、かつてこの場所で何が起きたのか、 そしてEclipse Labに隠された真相を辿っていきます。

使用技術

  • HTML
  • CSS
  • JavaScript

Archiveの探索や権限による情報の解禁、記録の閲覧など、 JavaScriptを多用してゲームとしてのインタラクションを実装しています。

研究施設や異常な存在を扱う、少しダークな世界観の作品です。 詳細な設定や物語は、Archiveを探索することで徐々に明らかになっていきます。

現在も制作を続けており、記録や探索要素などの追加・改善を行っています。

制作方法
