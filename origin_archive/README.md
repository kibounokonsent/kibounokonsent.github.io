# ORIGIN ARCHIVE — オリジン 公式設定資料集

MOON CORE（未来世界の資料集）と同じ形式・書き方を踏襲しつつ、オリジンの世界観に
合わせて12カテゴリーに再構成したものです。
「ORIGIN ARCHIVE 改修・設計提案書」に沿って、ナビゲーションの簡略化と
TECH MODE／MAGIC MODEの表示切替を追加しています。

## フォルダ構成

```
origin_archive/
├── index.html
├── assets/
│   └── images/
│       └── logo.svg        ← 仮ロゴ（差し替え可能）
├── css/
│   └── style.css            ← 見た目を全部担当
├── js/
│   └── app.js                ← サイトを動かす本体（通常は編集不要）
└── data/                     ← 設定そのもの。ここが一番重要
    ├── categories.js          ← カテゴリー一覧／歴史年表（TIMELINE）／ARTICLES配列の宣言
    ├── world.js                ← 世界概要
    ├── history.js              ← 歴史（年表は categories.js の TIMELINE に追加）
    ├── species.js               ← 種族
    ├── magic.js                 ← 魔法
    ├── tech.js                  ← 技術
    ├── cities.js                ← 都市
    ├── creature.js               ← 生物
    ├── org.js                    ← 組織
    ├── culture.js                 ← 文化・信仰
    ├── contract.js                 ← 契約（絶対契約を含む）
    ├── characters.js                ← キャラクター
    └── glossary.js                   ← 用語集（GLOSSARY配列。契約の構成要素11件を収録済み）
```

MOON CORE のように国家・組織を1団体＝1ファイルに分割する構成は取っていません。
今のところ都市11件・記事16件程度の規模のため、**カテゴリー単位で1ファイル**に
まとめてあります。将来、都市や組織が数十件規模に増えた場合は、MOON CORE と同様に
`data/cities/` のようなフォルダへ分割することをおすすめします。

## カテゴリー一覧（12）

`data/categories.js` の各カテゴリーに `primary:true` を付けると、常時表示される
ヘッダーナビに出ます（現在は5個）。それ以外は自動的に「その他」ドロップダウンに
まとまります。

| カテゴリー | ファイル | ナビ表示 | 備考 |
|---|---|---|---|
| 世界概要 | world.js | 常時 | |
| 歴史 | history.js + categories.js内のTIMELINE | 常時 | 年表形式で表示 |
| 種族 | species.js | その他 | 未設定 |
| 魔法 | magic.js | その他 | 未設定 |
| 技術 | tech.js | その他 | 未設定 |
| 都市 | cities.js | 常時 | 11都市（4都市は詳細あり、7都市は準備中） |
| 生物 | creature.js | その他 | 未設定 |
| 組織 | org.js | その他 | 未設定 |
| 文化・信仰 | culture.js | その他 | 未設定 |
| 契約 | contract.js | 常時 | 契約・絶対契約 |
| キャラクター | characters.js | 常時 | 未設定 |
| 用語集 | glossary.js | その他 | 契約の構成要素11件を収録 |

トップページ（EXPLORE）には常時表示の5カテゴリー＋「その他」カードのみを表示し、
12カテゴリーすべては `#/categories`（全カテゴリー）ページに集約しています。

## TECH MODE / MAGIC MODE

ヘッダー右上の `⚙ TECH` / `✦ MAGIC` ボタンで切り替えます。
中身の設定は変わらず、あくまで見た目の切り替えです。

- **MAGIC MODE**（ライト）：白背景＋紫。歯車は表示されず、光の粒子（星）だけが背景に浮かぶ
- **TECH MODE**（ダーク）：黒鉄色背景＋青系アクセント。カードにHUD風のコーナーブラケットが付き、
  背景には大小11個の歯車（⚙型・台形の歯）が低速で回転する。歯車はサイズ別に不透明度を分け
  （特大・大 = .12 / 中 = .09 / 小 = .06）、画面全体に分散配置している

## 歴史年表・世界地図

「歴史」「都市」の各カテゴリーページは、通常の記事一覧に加えて専用サブページへのボタンを表示します。

- 歴史 → 記事一覧の下に「歴史年表を見る」ボタン → `#/history/timeline`（年表専用ページ）
- 都市 → 記事一覧の下に「世界地図を見る」ボタン → `#/city/map`（都市の一覧ページ。
  都市間の位置関係はまだ設定が届いていないため、実際の地図ではなく一覧形式です）

## キャラクター画像

`data/characters.js` の各キャラクターに `image: 'assets/images/characters/xxx.webp'` の
ように画像パスを指定すると、カード・記事ページの両方に反映されます。画像を指定しない場合や
読み込みに失敗した場合は自動的に「NO IMAGE」のプレースホルダーが表示されます。

## 404ページ・モバイル対応

- 存在しない記事ID・カテゴリーキー、または `#/` から始まる未定義のURLにアクセスすると、
  専用の404ページ（「資料が見つかりませんでした」）が表示されます。トップ・カテゴリー一覧・
  検索への導線付きです。
- 画面幅1100px未満では上部の常時ナビは表示しません（ハンバーガーメニューなどの代替も
  あえて設けていません）。カテゴリーへはホームの EXPLORE、または「全カテゴリー」
  （`#/categories`）からアクセスする設計です。スマホのヘッダーは
  「ロゴ＋検索＋TECH/MAGIC切替」のみのシンプルな構成にしてあります。
- カテゴリーカラーのカードグリッド・TECHモードの歯車・世界地図・キャラクター画像・
  記事本文は、幅560〜960px前後を中心にレイアウトが縮小・折り返しされるようにしてあります。

## ロゴについて

`assets/images/logo.svg` を読み込む方式にしてあります。今は仮の紋章（四芒星）を
置いていますが、正式なロゴが決まったら **同じファイル名で上書きするだけ** で
反映されます。画像が読み込めない場合は自動的に ✦ マークにフォールバックします。

## 設定を追加したいとき

**新しい都市を追加する** → `data/cities.js` の末尾に
`pushCity('id', '名前', '区分', {features:[...], culture:[...], role:'...'})`
を1行追加するだけ（設定が未確定の場合は `pushCityStub('id', '名前')` だけでOK）。

**その他のカテゴリーに記事を追加する** → 対応する `data/xxx.js` を開き、
コメントに書かれているテンプレートをコピーして `ARTICLES.push({...})` する。

**用語を追加する** → `data/glossary.js` に
`GLOSSARY.push({term:'', reading:'', def:'', articleId:''})` を1行追加する。
検索は用語集の `term` も対象になるので、追加するだけで検索にも反映されます。

**歴史上の出来事を追加する** → `data/categories.js` の `TIMELINE` 配列に
`{era:'', title:'', tag:'', desc:''}` を1件追加する。

**新しいカテゴリーを追加する（現在12個・上限の目安）** → `data/categories.js` の
`CATEGORIES` 配列に1行追加し、対応する `data/xxx.js` を新しく作って
`index.html` に `<script src="data/xxx.js"></script>` を1行追加する。
常時ナビに出したい場合だけ `primary:true` を付ける（目安5個まで、それ以外は
自動で「その他」に入る）。ナビ・ホームのカード・記事ページの背景テーマは
`app.js` 側が自動追従するので、`style.css` 末尾の `body.theme-xxx` ブロックに
配色を1つ足すだけで反映されます。

- 世界の構造（三階層）・異世界との交流・未知の領域の詳細本文
- ノヴァリス／トルトゥーガ／アストリアス／ソル・レヴァンテ／ミル・フィーユ／
  パレットキッチン／ミューズヘイヴンの都市詳細（現在は名前のみのスタブ）
- 契約の各項目（契約者・対価・期間など）の個別ページ化（現状は用語集からのリンクのみ）
- 歴史年表の出来事（TIMELINE は現在空）
- 正式なロゴ画像・都市画像などのビジュアル素材
