# ORIGIN ARCHIVE — プロトタイプ

「地図を見る」のではなく、「地図から世界に入って、その世界の中で設定を発見する」ための試作です。

```
タイトル → 3D世界地図 → 都市を選ぶ（カメラが近づく） → 街へ入る → 街を歩く・調べる・話す
                                   ↓                              ↓
                               資料室（記事・検索） ←―――――――――――――┘
```

## 開き方

`index.html` をブラウザで開くだけで動きます（3D表示の部品 three.js をネットから読み込むので、オンラインで開いてください）。
※ `data/world.js` の `mapImage` に地図画像を入れた場合は、ブラウザの制限で直接開くと画像が読めないことがあります。そのときは簡易サーバー（例：`python -m http.server`）経由で開いてください。

│   ├── categories.js     資料室のカテゴリー
│   └── articles/
│       ├── world.js      「世界」の記事（記事の書き方の説明もここ）

## よくある追加・修正

| やりたいこと | 触るファイル |
|---|---|
| 都市を増やす・設定を直す | `data/cities.js` に1件コピーして書き換え |
| 都市の位置を動かす | `data/cities.js` の `pos`（中心が原点、◇の内側が既知の領土） |
| 都市の中で調べられる場所を足す | `data/cities.js` の `spots` |
| 街の見た目を変える | `data/cities.js` の `scene`（色・建物の種類・動く演出） |
| キャラクターを置く | `data/characters.js` に1件コピーして書き換え（サンプル2人は削除してOK） |
| 記事を書く | `data/articles/` のファイルに `ORIGIN.articles.push({...})` を追加 |
| 記事のファイルを増やす | `data/articles/xxx.js` を作り、`index.html` の「データ」の欄に `<script src="data/articles/xxx.js"></script>` を1行足す |
| 平面地図ができた | 画像を `assets/images/` に置き、`data/world.js` の `mapImage` にパスを書く |
| 階層の名前・高さを変える | `data/world.js` の `layers` |

### 記事の本文の書き方

テキストで書いた設定を、ほぼそのまま貼り付けられます。

```
【見出し】
本文。改行してもひとつの段落になります。

空行で段落が分かれます。
・「・」で始まる行は箇条書き
「小見出し」          ← 行全体を「」で囲む
> 注記の枠
[[contract|契約]]     ← 別の記事へのリンク
```

都市とキャラクターの記事は、`cities.js`・`characters.js` から自動で作られます（別に書く必要はありません）。

## キャラクターの反応

`data/characters.js` で設定します。

- **会話**：はじめて話しかけたとき（first）、2回目以降（again）、殴ったあと（afterPunch）で台詞が変わります
- **顔をつつく**：つつくたびに `poke` の上から順に進みます。`react` は flinch（びくっとする）／angry（怒る）／dodge（よける）／punch（殴ってくる）
- 立ち絵（`image`）を入れない間は、仮のシルエットで表示されます。顔の位置は `face` で調整できます

## 仮の設定になっているところ

プロトタイプとして動かすために、次の部分は仮で決めています。設定が決まったら差し替えてください。

- 三つの階層の名前（上層・中層・下層）と、各都市がどの階層に属するか
- 地図上の都市の位置と、自動生成の地形
- 各都市の「調べられる場所」の説明文（features / culture / role から起こした短い文）
- キャラクター2人（サンプル）

## 次の段階の候補

- 平面地図を描いて `mapImage` に設定 → 3D地図の地表に反映
- Scratch で試した演出（カメラの動き・入った瞬間の見せ方）をここに移す
- キャラクターの立ち絵と会話を入れる
- 都市ごとの背景を1枚絵にしたい場合は `scene.image` を使う
