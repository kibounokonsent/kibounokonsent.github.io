# 魔天楼 ARCHIVE（設定資料集サイト）

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## フォルダ構成
```
matenrou/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ app.js        … 画面を作るプログラム（普段は触らなくてOK）
│  ├─ icons.js      … 紋章・アイコン（キャラシートSVGから抽出した天使/悪魔/一般人の紋章）
│  └─ data/         … ★設定はここに書く
│     ├─ 00-categories.js   カテゴリー・サイト名・トップの紹介文
│     ├─ articles-*.js      記事（カテゴリーごと）
│     ├─ characters.js      キャラクター
│     └─ glossary.js        用語集
└─ assets/
   ├─ img/thumbnail.svg     高解像度サムネイル（1450×1000、元画像と同じ比率。ロゴは logo.svg と同じもの）
│  ├─ img/logo.svg         魔天楼ロゴ（文字はアウトライン化済み・白）
│  ├─ img/wing-angel.svg   天使の翼（左翼。右側は反転して使用）
│  ├─ img/wing-demon.svg / wing-demon-raised.svg  悪魔の翼（右翼。左側は反転）
│  ├─ img/feather-black.svg / feather-white.svg  羽根（白は黒から作成）。舞う羽根と羽根ペンに使用
   ├─ sheets/               キャラクターシート（天使・悪魔・一般人）
   └─ characters/           キャラ画像置き場
```

## 記事を追加する
`js/data/articles-○○.js` の `ARTICLES.push( … )` の中に1件足すだけです。
書き方は `articles-world.js` の先頭にまとめてあります。
本文で `[[記事ID]]` や `[[記事ID|表示名]]` と書くと記事へのリンクになります（まだ無い記事はグレー表示）。

新しいファイルを作った場合は、`index.html` の `<script src="js/data/...">` に1行追加してください。

## キャラクターを追加する
`js/data/characters.js` に追加します。`type` で使うシートが決まります。
- `angel` 天使シート（所属・階級・階位）
- `demon` 悪魔シート（契約・階級・種類）
- `human` 一般人シート（所属）

画像は `assets/characters/` に置き、`image: 'assets/characters/ファイル名.png'` と書くとシートの「見た目」欄に入ります。
記入例（`sample: true`）の3件は、実際のキャラを入れたら消してください。

## 塔（昇塔・降塔）
トップの「魔天楼の断面」と、`#/ascend`（昇塔＝天界へ）・`#/descend`（降塔＝魔界へ）のページは
`js/data/tower.js` から作られます。階の名前・説明・関連記事・扉の文章はここで書き換えられます。
- 昇塔：下から上へスクロールして昇る（開くと地上＝いちばん下から始まる）。最上階に「神への扉」
- 降塔：上から下へスクロールして潜る。最下層に「魔神への扉」
- 右側の高度計で今いる階がわかります（PCのみ）

## 機能
- 検索（入力途中で候補表示。記事・用語・キャラを横断。↑↓とEnterで選択）
- ライト／ダーク切替（右上）
- 階級カテゴリーは比較ラダー付き、用語集は五十音の行で絞り込み、キャラクターは種別で絞り込み
- 全記事一覧（更新順・名前順・カテゴリー順）

## デザインの考え方
- 一本の縦の軸。上からは冷たい光（天使）、下からは熾火（悪魔）。人の世はその間の薄暗い中層
- スクロールすると上の光が弱まり、下の熾火が強まる（ページを読み進める＝降りていく）
- カテゴリーは「天使側（冷たい光）」「悪魔側（熾火）」「人の世（無彩色）」のどれかに属し、
  その色はコード・線・ホバー時の光だけに薄く使う（app.js の SIDE で変更可能）
- 神話の図像：トップのロゴの背後に薔薇窓の線。昇塔の頂上に白く光る門と三対の天使の翼・舞い落ちる羽根、
  降塔の底に黒く沈む門と三対の悪魔の翼・煙・昇る火の粉
  （門の形は app.js の GATE_D、翼の画像は assets/img/wing-*.svg、翼の角度・大きさは style.css の .heaven-stage / .abyss-stage）
- この書は「章」と「節」でできている：カテゴリー＝章（第一章〜）、記事＝節。番号はカテゴリーの並び順と記事の並び順から自動で振られる
- カテゴリーのラテン語名は 00-categories.js の la、記事のラテン語の読みは各記事の reading
- 開いたときの演出：ロゴは線で描かれてから色が満ち、見出しは一文字ずつ墨がにじむように、本文は筆でなぞるように現れる（app.js の writeIn、style.css の .ch / .pen）
- 見出しの右には、キャラクターシートの紋章（天使・悪魔・一般人）を薄く置いている。翼は昇塔・降塔の門にだけ使う
- 画面左端の「天／魔」の線は、いま読んでいる深さ（スクロール位置）を示す

## 世界の中で行動する（体験の流れ）
読む → 転生する → 天界へ → 堕天する → 悪魔へ → 契約する → 時計の針を動かす → 異変（アポカリプス／ラグナロク）→ 深層へ

- **いまの身**：ヘッダー右の「人／天使／悪魔」。押すと「あなたの歩み」と次に行く場所が出る。最初からやり直すボタンもここ
- **転生する**：天使の節（天使・天使の階位・魂の循環）とトップの「魂の循環」に出る（人の身のとき）。天界の門をくぐり、天使の章へ
- **堕天する**：天使の身のとき、天使の章・天使の節・昇塔の「神への扉」に出る。翼が黒く染まり、悪魔の章へ
- **契約する**：契約の節（悪魔契約・代償の構造）と契約の章にいつでも出る。悪魔の身なら悪魔の章にも出る。七つの種類から選び、代償を見て契約する
- **世界の時計**：トップの「伍」と #/horologium。契約するまでは針が止まっている。9:00 から始まり、針を進めて 12:00（天）を越えるとラグナロク（神が降りてくる・幾千の翼）、戻して 6:00（魔）を越えるとアポカリプス（天使の侵攻と、迎え撃つ人と悪魔）
- **異変のあと**：サイト全体の空気が変わり、画面下に「時を戻す」が出る。深層（#/deep）と、昇塔・降塔の門の向こうが開く
- **深層の記事を書く**：ふつうの記事に `deep: true` を付けると、異変が起きるまで一覧にも検索にも出ず、起きたあと深層に並ぶ
- 文章や時刻（転生・堕天・契約の言葉、時計の開始時刻と異変の時刻）は js/data/world.js で変更できる
- 歩みは閲覧者のブラウザに保存される（ほかの人とは共有されない）
