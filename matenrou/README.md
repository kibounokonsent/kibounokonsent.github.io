# 魔天楼 ARCHIVE（設定資料集サイト）

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## サイトの構成（塔のかたち）
この書は塔の形をしています。すべての記事は、三つの「領域」のどれかに属します。

| 領域 | 内容 | 章 |
|---|---|---|
| ↑ 昇塔（天使と天界） | 天使の設定・天使の階級・天界側 | 天使／天使の階級／天界へ通じるもの |
| ● 地上（人の世） | 人間の世界・契約・組織・人物 | 世界の成り立ち／契約と代償／組織・団体／武器と覚醒／キャラクター |
| ↓ 降塔（悪魔と魔界） | 悪魔の設定・悪魔の階級・魔界側 | 悪魔／七つの種類／悪魔の階級 |

- 「階級」は独立した章ではなく、天使の階級は昇塔に、悪魔の階級は降塔に入っています。両方をくらべる表は地上の「塔と階級」にあります
- 章の番号（第一章〜）は、昇塔→地上→降塔の順に自動で振られます
- 領域・章は `js/data/00-categories.js` の `REALMS` と `CATEGORIES` で変えられます

## フォルダ構成
```
matenrou/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ app.js        … 画面を作るプログラム（普段は触らなくてOK）
│  ├─ icons.js / emblems.js … 紋章・アイコン
│  └─ data/         … ★設定はここに書く
│     ├─ 00-categories.js   領域・章・サイト名・古いリンクの読み替え
│     ├─ articles-heaven.js ↑昇塔の記事
│     ├─ articles-ground.js ●地上の記事
│     ├─ articles-abyss.js  ↓降塔の記事
│     ├─ articles-deep.js   深層（裏設定）
│     ├─ characters.js / glossary.js / tower.js / world.js
└─ assets/ … 画像（翼・羽根・ロゴ・キャラ・キャラシート）
```

## 記事を追加する
領域に合ったファイル（`articles-heaven.js` など）の `ARTICLES.push( … )` の中に1件足すだけです。
書き方は `articles-heaven.js` の先頭にまとめてあります。`cat` には章のIDを書きます。

- 本文で `[[記事ID]]`・`[[記事ID|表示名]]` と書くと記事へのリンクになります（まだ無い記事はグレー表示）
- 見出しに `key: 'ou'` のような名前を付けると、`[[angel-ranks/ou|王級]]` のように**記事の中のその項目へ直接**リンクできます
- 見出しに `emb: 'a-ou'` を付けると、見出しの左に紋章が出ます
- 統合した古い記事ID（`rank-ou`・`crest`・`side-effects` など）で書いても、`ALIASES` で新しい場所へ飛びます

新しいファイルを作った場合は、`index.html` の `<script src="js/data/..." defer>` に1行追加してください。

## キャラクターを追加する
`js/data/characters.js` に追加します。画像は `assets/characters/` に置きます。
- `type`：`angel`（天使）／`demon`（悪魔）／`human`（人）
- シートは元のキャラシと同じ配置（名前／所属・契約／階級と紋章／階位・種類／見た目／設定）を、サイトの紙面に合わせて描き直したものです
- `forms`：階級で姿が変わるキャラ（ドルネラヒドなど）は `{ rank, image }` を低い順に並べると、霊級→命級→王級→司級のタブで切り替えられます
- 空欄の項目は「まだ記されていない」と表示されます
- `spoiler: true` を付けると、ネタバレなしの人には伏せて表示されます

## ネタバレあり／なし（入口の門）
初めて開いたとき、門をくぐる画面で「すべてを知る（ネタバレあり）」か「核心を伏せる（なし）」を選びます。
あとから右上の「いまの身」パネルでいつでも選び直せます。
- 記事全体を伏せる：記事に `spoiler: true`
- 記事の一節だけ伏せる：`sections` の中の一節に `spoiler: true`
- キャラを伏せる：キャラに `spoiler: true`
- 深層（`deep: true`）は「ネタバレあり」かつ異変のあとでだけ開きます

## 姿による空気の変化
- 天使になると：サイト全体が白みがかり、画面の端から白い翼がのぞきます
- 悪魔になると：サイト全体が黒みがかり、画面の端から悪魔の翼がのぞきます
- ラグナロク：幾千の翼をもつ存在（神）が空から降り、羽ペンの羽根が大量に舞い落ちます
- アポカリプス：翼の天使たちが侵攻し、人と悪魔が迎え撃ちます
- ドルネラヒドとモルツゥスの姿はキャラクターのページでだけ使っています（演出には出しません）

## 塔（昇塔・降塔）
トップの「魔天楼の断面」と、`#/ascend`（昇塔＝天界へ）・`#/descend`（降塔＝魔界へ）のページは
`js/data/tower.js` から作られます。階の名前・説明・関連記事・扉の文章はここで書き換えられます。
- 昇塔：下から上へスクロールして昇る（開くと地上＝いちばん下から始まる）。最上階に「神への扉」
- 降塔：上から下へスクロールして潜る。最下層に「魔神への扉」
- 右側の高度計で今いる階がわかります（PCのみ）

## 探し方・読み方
- **ヘッダー**：↑昇塔／●地上／↓降塔 の三つの領域と、人物・用語・索引
- **目次**（右上のボタン）：すべての領域・章・節をひと目で見られる引き出し。スマホではここに検索も入る
- **領域ページ**（#/r/heaven など）：その領域の章と節の一覧、横に「塔の階」（階級へ直接飛べる）
- **記事ページ**：左にその領域の目次、右に情報欄と「この節の項」（いま読んでいる見出しに印が付く）。下に関連する節と、前後の節
- 検索（入力途中で候補表示。記事・用語・キャラを横断。↑↓とEnterで選択）、ライト／ダーク切替
- すべての節（章の順・新しい順・名の順、領域で絞り込み）

## 軽さのための決まりごと（style.css を触るとき）
- 画面全体に重ねるものには `mix-blend-mode`・`backdrop-filter`・`filter` を使わない
- 動かすのは `transform` と `opacity` だけ。光（drop-shadow など）は**動かない画像の側**に付け、動きはそれを包む箱に付ける
- 画面の外にある門の演出は止まる。開いたときの「書く」演出は、見えている部分だけを約1秒で書き終える

## デザインの考え方
- 一本の縦の軸。上からは冷たい光（天使）、下からは熾火（悪魔）。人の世はその間の薄暗い中層
- スクロールすると上の光が弱まり、下の熾火が強まる（ページを読み進める＝降りていく）
- カテゴリーは「天使側（冷たい光）」「悪魔側（熾火）」「人の世（無彩色）」のどれかに属し、
  その色はコード・線・ホバー時の光だけに薄く使う（app.js の SIDE で変更可能）
- 神話の図像：トップのロゴの背後に薔薇窓の線。昇塔の頂上に白く光る門と三対の天使の翼・舞い落ちる羽根、
  降塔の底に黒く沈む門と三対の悪魔の翼・煙・昇る火の粉
  （門の形は app.js の GATE_D、翼の画像は assets/img/wing-*.svg、翼の角度・大きさは style.css の .heaven-stage / .abyss-stage）
- この書は「章」と「節」でできている：カテゴリー＝章（第一章〜）、記事＝節。番号はカテゴリーの並び順と記事の並び順から自動で振られる
- カテゴリーのラテン語名は 00-categories.js の la、記事のラテン語の読みは各記事の reading
- 開いたときの演出：ロゴは線で描かれてから色が満ち、見出しは一文字ずつ墨がにじむように、本文は筆でなぞるように現れる（app.js の writeIn、style.css の .ch / .pen）
- 見出しの右には、キャラクターシートの紋章（天使・悪魔・一般人）を薄く置いている。翼は昇塔・降塔の門にだけ使う
- 画面左端の「天／魔」の線は、いま読んでいる深さ（スクロール位置）を示す

## 音（遠い鐘と、聖堂のオルガン）
音声ファイルは使わず、`js/sound.js` がブラウザの中で鐘とオルガンの音を作ります（サーバー・通信なし）。
- **鳴るのは物語の節目だけ**：入口の門／転生／堕天／契約の封／ラグナロク／アポカリプス／塔の門（昇塔・降塔の頂と底）。ふだん読んでいるあいだは、押したときの小さな音だけ（異変のあとはうすい音楽も）
- **世界の時計**：針を回すと5分ごとにチク・タク、ちょうどの時刻を通ると小さな鐘（12時＝天に近いほど高く、6時＝魔に近いほど低い）
- **ラグナロク**：あえて神を歓迎するように、ティンパニのロールから、鐘・オルガン・聖歌隊が「歓喜の歌」（ベートーヴェン 第九）をニ長調で高らかに奏で、最後の主音でティンパニが轟き、すべての鐘が鳴りわたる。旋律は `SCENES.ragnarok` の `MEL`
- **アポカリプス**：戦の太鼓、乱打される低い鐘、地鳴りと崩れる音、下から唸る聖歌隊と、上から軋むように昇ってくる天使の声
- **異変のあとの音楽**：ラグナロク・アポカリプスのあと、それぞれの音楽がうすく流れつづける（ラグナロク＝光の満ちたコラールと、遠くで鳴る歓喜の歌の断片／アポカリプス＝底のうなり、遠い鐘、ときどき太鼓）。「時を戻す」で消える。大きさは `BGM_LEVEL`
- **押したときの音**：リンクやボタンを押すと、小さな鐘をそっと鳴らしたような、短く軽い音。大きさは `TAP_LEVEL`（0で鳴らさない）
- **音色**：（ラグナロク以外は）長調の明るい和音は使わず、三度を抜いた五度や二度の和音と、わずかにずらした二本のパイプの冷たいうなり。鐘は遠くでくぐもるように
- **軽さ**：音はその場で合成し続けず、次に要りそうな音を手の空いたときに一度だけ録音しておき、鳴らすときは再生するだけ。何も鳴っていないときは音の仕組みごと眠ります
- **鳴らす／鳴らさない**：入口の門のボタンと、ヘッダー右の鐘のボタン（閲覧者のブラウザに保存）。ブラウザの決まりで、最初にどこかを押すまでは鳴りません
- 全体の音量は `sound.js` 先頭の `VOLUME`、各場面の音は `SCENES`（鐘の高さ・和音・タイミング）で変えられます

## 世界の中で行動する（体験の流れ）
読む → 転生する → 天界へ → 堕天する → 悪魔へ → 契約する → 時計の針を動かす → 異変（アポカリプス／ラグナロク）→ 深層へ

- **いまの身**：ヘッダー右の「人／天使／悪魔」。押すと「あなたの歩み」と次に行く場所が出る。最初からやり直すボタンもここ
- **転生する**：天使の節（天使・天使の階位・魂の循環）とトップの「魂の循環」に出る（人の身のとき）。天界の門をくぐり、天使の章へ
- **堕天する**：天使の身のとき、天使の章・天使の節・昇塔の「神への扉」に出る。翼が黒く染まり、悪魔の章へ
- **契約する**：契約の節と地上の「契約と代償」の章にいつでも出る。悪魔の身なら降塔の章にも出る。七つの種類から選び、代償を見て契約する
- **世界の時計**：トップの「伍」と #/horologium。契約するまでは針が止まっている。9:00 から始まり、針を進めて 12:00（天）を越えるとラグナロク（神が降りてくる・幾千の翼）、戻して 6:00（魔）を越えるとアポカリプス（天使の侵攻と、迎え撃つ人と悪魔）
- **異変のあと**：サイト全体の空気が変わり、画面下に「時を戻す」が出る。深層（#/deep）と、昇塔・降塔の門の向こうが開く
- **深層の記事を書く**：ふつうの記事に `deep: true` を付けると、異変が起きるまで一覧にも検索にも出ず、起きたあと深層に並ぶ
- 文章や時刻（転生・堕天・契約の言葉、時計の開始時刻と異変の時刻）は js/data/world.js で変更できる
- 歩みは閲覧者のブラウザに保存される（ほかの人とは共有されない）
